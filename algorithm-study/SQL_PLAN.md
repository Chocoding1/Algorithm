# SQL 코딩테스트 4주 입문 계획

## 목표와 운영 방식

- 대상: SQL 문제 풀이 경험 10문제 미만
- 방언: 프로그래머스 `MySQL`
- 빈도: 월요일~금요일 매일 1문제, 일요일 주간 혼합 1문제
- 토요일: 휴식
- 첫 4주의 우선순위: 속도보다 결과 행의 단위, 데이터 흐름, 중복과 NULL을 정확히 이해한다.
- SQL 문제는 `daily/YYYY-MM-DD/sql/문제명/`에 `solution.sql`과 `review.md`로 저장한다.
- 로컬 DB 구축은 필수로 하지 않는다. 프로그래머스 실행·제출 결과를 공식 검증으로 사용한다.

## 매일 풀이 순서

1. 결과의 한 행이 무엇을 의미해야 하는지 한 문장으로 적는다.
2. 기준 테이블을 고르고 JOIN이 필요한지 확인한다.
3. `WHERE`로 어떤 원본 행을 제외할지 정한다.
4. 집계가 필요하면 `GROUP BY`의 한 그룹이 무엇인지 정의한다.
5. 그룹 조건은 `HAVING`, 출력 조건은 `SELECT`, 최종 순서는 `ORDER BY`로 정리한다.
6. 중복 행, `NULL`, 동률과 정렬 기준을 확인한 뒤 제출한다.

사용자가 적는 내용은 다음 세 문장으로 제한한다. 상세 분석은 Codex가 작성한다.

- `출력해야 할 값`: 최종 결과에 어떤 열이나 계산값을 보여줘야 하는가?
- `조회할 테이블과 한 행의 의미`: `FROM`에서 어느 테이블을 읽고, 조회 시작 시 그 테이블의 한 행은 무엇을 나타내는가? `JOIN`이나 `GROUP BY` 뒤에 한 행의 의미가 바뀌는가?
- `행을 바꾸는 조건과 최종 정렬`: 각 SQL 절이 행을 제외·증가·축약하는지와 마지막 정렬 기준은 무엇인가?

## 1주차: 조회와 필터

목표 시간은 문제당 15~20분이며 프로그래머스 Lv.1을 중심으로 푼다.

| 일차 | 학습 주제 | 확인할 핵심 |
|---|---|---|
| 1 | `SELECT`, 컬럼, 별칭 | 필요한 컬럼만 정확한 이름으로 출력 |
| 2 | `WHERE`, 비교 연산자 | 출력 조건과 원본 행 필터 구분 |
| 3 | `AND`, `OR`, `IN`, `BETWEEN` | 괄호와 경계값 포함 여부 |
| 4 | `LIKE` | `%`, `_`가 의미하는 범위 |
| 5 | `ORDER BY`, `LIMIT`, `DISTINCT` | 동률일 때 두 번째 정렬 기준 |
| 6 | 1주차 혼합 | 필터부터 출력·정렬까지 독립 작성 |

진급 기준은 6문제 중 4문제 이상을 작은 힌트 없이 성공하고, `WHERE`와 `ORDER BY`의 역할을 설명하는 것이다. 부족하면 2주차 초반 2문제를 Lv.1 필터 문제로 유지한다.

## 2주차: 집계와 NULL

목표 시간은 문제당 20~25분이며 Lv.1에서 시작해 Lv.2를 섞는다.

| 일차 | 학습 주제 | 확인할 핵심 |
|---|---|---|
| 1 | `COUNT`, `SUM`, `AVG`, `MAX`, `MIN` | `COUNT(*)`와 `COUNT(column)`의 NULL 차이 |
| 2 | `GROUP BY` | 결과 한 행과 그룹 한 개의 의미 |
| 3 | `HAVING` | `WHERE`와 그룹 필터의 차이 |
| 4 | `IS NULL`, `COALESCE` | NULL은 `=`로 비교하지 않음 |
| 5 | `CASE`, 조건부 집계 | 조건을 값으로 바꾸어 집계하기 |
| 6 | 2주차 혼합 | 필터·그룹·그룹 필터 조합 |

진급 기준은 그룹별 결과에서 한 행이 무엇을 나타내는지 설명하고, WHERE와 HAVING을 구분해 4문제 이상 독립 성공하는 것이다.

## 3주차: JOIN과 행의 증가

목표 시간은 문제당 25~30분이며 프로그래머스 Lv.2를 중심으로 푼다.

| 일차 | 학습 주제 | 확인할 핵심 |
|---|---|---|
| 1 | `INNER JOIN` | 양쪽에 존재하는 행만 남는 이유 |
| 2 | `LEFT JOIN` | 오른쪽에 없는 행과 NULL 처리 |
| 3 | 안티 조인, `NOT EXISTS` | 존재하지 않는 관계 찾기 |
| 4 | 다중 JOIN | 각 JOIN 뒤 결과 행의 단위 추적 |
| 5 | 1:N 관계와 중복 | JOIN으로 행이 늘어나는 이유 |
| 6 | 3주차 혼합 | JOIN·필터·집계 조합 |

진급 기준은 JOIN 전후 예상 행 수를 설명하고, 중복을 무조건 `DISTINCT`로 숨기지 않은 채 4문제 이상 독립 성공하는 것이다.

## 4주차: 서브쿼리와 실전 함수

목표 시간은 문제당 25~35분이며 Lv.2를 중심으로 진행한다.

| 일차 | 학습 주제 | 확인할 핵심 |
|---|---|---|
| 1 | 스칼라·목록 서브쿼리 | 서브쿼리 결과 행 수와 비교 연산자 |
| 2 | `EXISTS`, 상관 서브쿼리 | 존재 여부만 필요한 경우 |
| 3 | 문자열 함수 | 대소문자·부분 문자열·결합 |
| 4 | 날짜 함수 | 날짜 범위와 마지막 시각 경계 |
| 5 | 조건부 집계·기초 윈도 함수 | 그룹 축약과 원본 행 유지의 차이 |
| 6 | 4주차 혼합 | 여러 절을 사용해 결과 근거 설명 |

4주 종료 후 첫 제출 성공률, 목표 시간 달성률, 힌트 의존률과 `JOIN·중복`, `집계·그룹`, `NULL`, `필터`, `정렬·출력` 오류를 평가해 다음 4주의 Lv.2 비율과 윈도 함수·복합 JOIN 학습량을 정한다.

## SQL 복습 등급

- A: 목표 시간 안에 힌트 없이 첫 제출 통과하고 결과 행의 단위와 중복·NULL 영향을 설명함. 동일 문제 재풀이는 생략한다.
- B: 성공했지만 시간 초과, 작은 힌트, 오답 제출, 문법 오류 또는 결과 근거가 불명확함. 2~3일 뒤 핵심 절을 5분 이내로 재작성한다.
- C: 실패, 핵심 힌트·해설·정답 쿼리 확인 또는 JOIN·그룹 단위를 완성하지 못함. 2~3일 뒤 그날 SQL 문제 대신 동일 문제를 다시 푼다.

일요일 혼합 문제에서 처음 보는 문제를 힌트 없이 성공했는지를 주간 전이 지표로 사용한다.
