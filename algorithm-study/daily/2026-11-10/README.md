# 2026-11-10 학습

오늘은 어제 성공한 그래프 기본 문제를 반복하지 않고, 서로 다른 조건에서 전체 비용을 최소화하는 두 문제로 확장한다. 신규 문제이므로 풀이 전에는 핵심 유형과 연결된 원본 문제를 공개하지 않는다.

## Java 알고리즘 2문제

### 1. 섬 연결하기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42861
- 플랫폼 / 난이도: 프로그래머스 Lv.3
- 목표 시간: 45분
- 60% 힌트 판단 시점: 27분
- 추천 이유: 연결 조건과 전체 비용을 동시에 만족시키는 선택 기준을 설계하고, 선택 과정이 항상 최소 결과를 보장하는지 설명하는 연습을 한다.
- 풀이 전 확인:
  - 모든 섬이 서로 통행 가능하다는 조건을 작은 예제에서 어떻게 확인할 수 있는가?
  - 모든 다리 조합을 직접 비교하면 입력이 커질 때 경우의 수가 어떻게 늘어나는가?
  - 선택한 방법이 더 저렴한 결과를 놓치지 않는다고 어떻게 검증할 수 있는가?
- 결과: 30분, 설계 15분, 첫 통과 전 오답 2회
- 복습 등급: B — 최소 비용 간선과 Union-Find 설계는 독립적으로 찾았지만 방문 상태와 연결 요소를 혼동하고 대표가 아닌 정점 번호를 합쳐 반례 도움 후 수정
- 실제 풀이: 비용이 낮은 간선부터 확인하고 서로 다른 연결 요소를 잇는 간선만 선택하는 Kruskal
- 주요 학습점: `visited`는 연결 요소를 표현하지 못하며, `union`은 반드시 두 정점의 대표를 연결해야 한다.
- 복습 일정: 2026-11-12 D+1, 2026-11-13 D+3, 2026-11-18 유형 비공개 변형

### 2. 합승 택시 요금

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/72413
- 플랫폼 / 난이도: 프로그래머스 Lv.3
- 목표 시간: 50분
- 60% 힌트 판단 시점: 30분
- 추천 이유: 여러 출발·도착 조건이 결합된 비용 문제에서 반복 계산을 줄이고 모든 후보를 빠짐없이 비교하는 설계를 연습한다.
- 풀이 전 확인:
  - 최종 요금은 함께 이동한 구간과 각자 이동한 구간을 어떻게 합한 값인가?
  - 이동 경로를 모두 직접 만들면 어떤 계산이 반복되는가?
  - 합승하지 않는 경우까지 정답 후보에 포함됐다고 어떻게 확인할 수 있는가?
- 결과: 60분 독립 고민 후 미제출, 정답 코드 학습 및 공개 예제 로컬 검증
- 복습 등급: C — 다익스트라 유형과 후보별 반복 병목은 인식했지만 세 출발점의 거리 배열 재사용 설계를 완성하지 못함
- 실제 학습 코드: `s`, `a`, `b`에서 우선순위 큐 다익스트라를 각각 실행하고 모든 합승 종료 지점의 세 거리 합을 비교
- 주요 학습점: 후보마다 탐색하지 않고 필요한 출발점별 최단거리 결과를 미리 계산해 재사용하며, 공식 대안인 플로이드–워셜은 모든 지점 쌍을 한 번에 계산한다.
- 복습 일정: 2026-11-13 동일 문제 재도전, 성공 시 2026-11-20 유형 비공개 변형

두 문제 모두 60% 시점에 구현 가능한 설계가 없으면 현재까지 확인한 병목과 막힌 지점을 적고 작은 힌트를 요청한다. 합계 목표 시간은 95분이다.

## MySQL SQL 2문제

### 1. 오랜 기간 보호한 동물(2)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/59411
- 난이도: 프로그래머스 SQL Lv.3
- 오늘 연습 범주: JOIN 결과의 행 단위·두 날짜의 차이·정렬·개수 제한
- 목표 시간: 20분
- 추천 이유: 두 테이블을 연결한 뒤 한 행이 나타내는 동물을 유지하면서, 두 시점으로 계산한 값을 기준으로 결과를 고르는 연습을 한다.
- 결과: 8분 30초, 첫 통과 전 오답 1회
- 복습 등급: C — 날짜 차이 함수에 ID 컬럼을 사용한 뒤 완성 쿼리를 확인해 수정
- 실제 풀이: 입소·입양 정보를 동물 ID로 연결하고 두 날짜의 차이를 내림차순 정렬한 뒤 상위 2행 선택
- 주요 학습점: 날짜 함수에는 실제 날짜 컬럼을 전달하고, 시각까지 정확히 비교할 때는 `TIMESTAMPDIFF`를 사용할 수 있다.
- 복습 일정: 2026-11-13 현재 쿼리·회고 없이 동일 문제 재도전

### 2. 보호소에서 중성화한 동물

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/59045
- 난이도: 프로그래머스 SQL Lv.4
- 오늘 연습 범주: JOIN 전후 값 비교·문자열 조건·정렬
- 목표 시간: 20분
- 추천 이유: 같은 대상의 이전 상태와 이후 상태를 한 행에서 비교하고, 요구된 변화만 정확히 필터링하는 연습을 한다.
- 결과: 7분 20초, 첫 제출 통과
- 복습 등급: A — 입소·입양 상태의 두 전환 조건을 오류와 힌트 없이 정확히 구현
- 실제 풀이: 동물 ID로 두 테이블을 연결하고 성별에 맞는 중성화 전후 상태를 비교한 뒤 ID 오름차순 정렬
- 주요 학습점: `AND`가 `OR`보다 먼저 계산되어 원본도 정확하지만, 의미 단위별 괄호가 가독성과 수정 안전성을 높인다.
- 복습 일정: 동일 문제 재도전 생략, 주간 SQL 혼합 문제에서 전이 확인

SQL 두 문제의 합계 목표는 40분이다. 제출 전에는 출력 컬럼, 연결 후 한 행의 의미, 필터 조건, 정렬과 결과 개수 제한을 문제 요구사항과 한 줄씩 대조한다.

## 짧은 복습

오늘은 별도의 짧은 회상을 추가하지 않았다. `섬 연결하기`는 핵심 유형을 독립 선택했지만 구현 반례 2개를 통해 Union-Find 대표 연결을 보완했고, `합승 택시 요금`은 정답 코드 학습으로 종료했다. SQL은 한 문제 C, 한 문제 A로 마무리했다.

- MySQL: JOIN 자체는 안정적으로 적용하고 있다. 날짜 함수 인자 선택은 재도전이 필요하지만, 전후 상태 비교 문제는 7분 20초에 첫 제출로 통과했다.
