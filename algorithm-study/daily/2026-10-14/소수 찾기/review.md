- 풀이 전 사고와 실제 코드의 차이: 계획한 DFS를 그대로 구현했다. 다만 재귀 중간에 선행 `0`을 문자열에서 제거해 `targetLength`가 사용한 종이 조각 수와 달라졌고, 길이별 DFS를 반복하면서 불필요한 탐색이 생겼다. `Integer.parseInt("011") == 11`이므로 선행 `0`을 직접 제거할 필요는 없다.
- 코드 개선 포인트: **가독성·상수 비용 개선** — 재귀를 길이별로 다시 시작하지 않고, 한 번의 DFS에서 숫자를 하나 추가할 때마다 현재 정수를 집합에 넣으면 된다. 문자열 연결·`normalize()`·`Set<String>`을 없애고 `current * 10 + digit`과 `Set<Integer>`를 사용하면 상태의 의미가 명확해진다. 점근적인 팩토리얼 탐색은 동일하다.
- 클린 코드 예시:

```java
import java.util.HashSet;
import java.util.Set;

// 프로그래머스 Lv.2
public class 소수_찾기 {

    private final Set<Integer> candidates = new HashSet<>();

    public int solution(String numbers) {
        candidates.clear();
        generate(numbers, new boolean[numbers.length()], 0, 0);

        int answer = 0;
        for (int candidate : candidates) {
            if (isPrime(candidate)) {
                answer++;
            }
        }
        return answer;
    }

    private void generate(String numbers, boolean[] visited, int value, int depth) {
        if (depth > 0) {
            candidates.add(value);
        }

        for (int i = 0; i < numbers.length(); i++) {
            if (visited[i]) {
                continue;
            }

            visited[i] = true;
            generate(numbers, visited,
                    value * 10 + (numbers.charAt(i) - '0'), depth + 1);
            visited[i] = false;
        }
    }

    private boolean isPrime(int number) {
        if (number < 2) {
            return false;
        }

        for (int divisor = 2; divisor * divisor <= number; divisor++) {
            if (number % divisor == 0) {
                return false;
            }
        }
        return true;
    }
}
```

- 풀이 후 새로 배운 점: 약수가 존재한다면 작은 쪽 약수는 반드시 제곱근 이하이므로 제곱근과 같은 약수도 검사해야 한다. `i < sqrt(n)`은 `4`, `9`, `25`, `49` 같은 제곱수를 놓치므로 `i * i <= n`을 사용한다. 숫자 조각 순열은 서로 다른 인덱스의 선택 순서를 모두 다뤄야 하며, 중복된 숫자 값은 정수 집합이 제거한다.
- 다음 문제에 적용할 한 문장 규칙: **길이 1부터 N까지의 모든 순열이 필요하면 한 번의 백트래킹에서 각 깊이의 상태를 결과 후보로 처리하고, 소수 판정은 `divisor * divisor <= number`까지 확인한다.**
- 복습에 포함할 학습 포인트: 사용·복구 상태, 선행 0을 정수 집합이 자연스럽게 처리하는 이유, 제곱근 경계, 순열 상태 수
- 오류 분류: 구현·시간 관리 — 소수 판정에서 제곱근과 같은 약수를 제외해 오답 1회, 목표 1분 초과
- 시간복잡도: 후보 생성은 `S = Σ P(N, r)` (`1 ≤ r ≤ N`)개의 순열 상태를 방문하고, 서로 다른 후보마다 최대 `O(√M)` 소수 판정을 수행한다. `N ≤ 7`에서 충분함
- 공간복잡도: 후보 정수 집합과 탐색 상태를 포함해 `O(S)`, 재귀 호출 깊이는 `O(N)`
