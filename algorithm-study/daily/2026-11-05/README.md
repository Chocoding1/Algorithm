- 완료: Java 2문제 + MySQL 2문제, 모두 최종 성공

- 목표 시간 달성: 3/4 — `주차 요금 계산`만 목표 40분 초과
- 복습 등급: A 1문제, B 3문제, C 0문제
- 잘한 점: 차량별 상태를 독립 설계해 구현 문제를 첫 제출로 통과했고, 첫 1:N JOIN 집계 문제도 빠르고 정확하게 해결했다. `정수 삼각형`의 시간 초과 원인을 같은 상태의 반복 계산으로 찾아 메모이제이션을 독립 적용했다.
- 보완할 점: 구현 문제에서 계산 단계를 나누지 않아 시간이 길어졌고, 재귀 설계 전에 전체 경로 수를 계산하지 못했다. SQL에서는 작성 순서상 `JOIN ... ON`이 `WHERE`보다 앞선다는 기본 구문을 다시 고정해야 한다.
- 다음 학습에서 확인할 것: 구현 전 후처리·경계 계산을 작은 단계로 나누기, 재귀 전에 경로 수와 서로 합쳐지는 상태 확인하기, SQL을 `FROM → JOIN/ON → WHERE → GROUP BY → HAVING → SELECT → ORDER BY` 순서로 읽기
