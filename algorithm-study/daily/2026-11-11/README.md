## Java 알고리즘 2문제

### 1. 전력망을 둘로 나누기 재도전

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/86971
- 플랫폼 / 난이도: 프로그래머스 Lv.2
- 목표 시간: 30분
- 60% 힌트 판단 시점: 18분
- 추천 이유: 11월 8일 C등급 동일 문제 재도전이다. 이전 코드·회고·대화를 보지 않고, 한쪽 연결 영역의 크기와 최종 차이를 독립적으로 재현하는지 확인한다.
- 풀이 전 확인:
  - 재귀 깊이와 방문한 전체 송전탑 수를 구분했는가?
  - 한쪽 송전탑 수를 구하면 다른 쪽 수를 어떻게 구할 수 있는가?
  - 후보 전선이 바뀐 때 어떤 값을 새로 초기화해야 하는가?
- 결과: 45분, 20분에 설계 확정, 힌트 없음, 첫 제출 통과
- 복습 등급: B — 간선별 제외·DFS 크기 반환·차이 계산을 독립 재현했지만 목표를 15분 초과했고, DFS 반환 후 방문 해제 누락을 구현 중 수정
- 실제 풀이: 전선을 하나씩 제외한 뒤 DFS로 한쪽 연결 요소의 크기를 구하는 `O(N²)` 풀이
- 배운 점: 한쪽이 `count`면 다른 쪽은 `n - count`이며, 전선 후보마다 새 `visited`를 사용하면 재귀 복귀 시 방문 해제를 관리할 필요가 없음
- 복습 일정: 2026-11-12 D+1, 2026-11-13 D+3, 2026-11-18 D+7 변형

### 2. 순위

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/49191
- 플랫폼 / 난이도: 프로그래머스 Lv.3
- 목표 시간: 45분
- 60% 힌트 판단 시점: 27분
- 추천 이유: 입력에 직접 나오지 않은 관계를 포함해 확정 가능한 결과를 빠짐없이 판단하는 설계를 연습한다. 신규 문제이므로 풀이 전에는 핵심 유형을 공개하지 않는다.
- 풀이 전 확인:
  - 정확한 순위가 확정되려면 한 선수와 나머지 선수들 사이에 어떤 정보가 필요한가?
  - 직접 주어진 결과만 확인하면 놓치는 경우는 무엇인가?
  - `n = 1`인 경우에도 같은 판정 조건이 성립하는가?
- 결과: 40분 이상 독립 고민 후 정답 코드 학습, 공식 미제출, 공개 예제 `2` 로컬 확인
- 복습 등급: C — 순위 판정 조건과 정방향·역방향 그래프는 찾았지만 경로 길이·중복 경로를 도달 정점 수로 잘못 집계해 핵심 힌트와 전체 코드를 확인
- 복습 일정: 2026-11-15 동일 문제 재도전, 성공 시 2026-11-21 유형 비공개 변형

## MySQL SQL 2문제

### 1. 대여 기록이 존재하는 자동차 리스트 구하기 재도전

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/157341
- 난이도: 프로그래머스 SQL Lv.3
- 오늘 연습 범주: `EXISTS`·상관 서브쿼리·1:N 중복·날짜 범위
- 목표 시간: 15분
- 추천 이유: 11월 9일에 완성 쿼리를 확인한 C등급 문제다. 기존 쿼리와 회고를 보지 않고, 자동차 한 행을 유지하면서 조건에 맞는 대여 기록의 존재 여부를 독립 재현한다.
- 결과: 3분 40초, 무힌트, 첫 제출 통과, 오류 없음
- 복습 등급: A — `EXISTS`가 아닌 유효한 `JOIN + DISTINCT` 대안으로 날짜 범위·중복·정렬을 정확히 독립 재현
- 복습 일정: 2026-11-15에 `JOIN + DISTINCT`와 `EXISTS`의 행 변화 차이만 2~3분 비교

### 2. 헤비 유저가 소유한 장소

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/77487
- 난이도: 프로그래머스 SQL Lv.3
