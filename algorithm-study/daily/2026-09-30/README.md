## 오늘의 평가

- `프로세스`는 7분 만에 큐에 우선순위와 원본 인덱스를 함께 저장하는 설계를 확정하고 20분 안에 첫 제출로 통과했다. `다리를 지나는 트럭`에서 어려웠던 큐 상태 정의를 더 단순한 문제에서는 안정적으로 수행했다.
- `프로세스`의 정답성 항목에는 복잡도만 작성했다. 큐가 남은 대기 순서를, 최대 힙이 남은 우선순위 전체를 나타낸다는 불변식과 문제 규칙의 대응을 설명하는 연습이 필요하다.
- `주식가격`은 `O(N²)` 단순 풀이의 병목까지는 정확히 찾았지만, 현재 값이 이전의 미확정 인덱스들을 확정한다는 역방향 관점과 단조 스택 설계를 떠올리지 못했다. 이번 문제는 패턴 학습 문제로 처리하고 10월 2일에 정답 코드 없이 재도전한다.
- `할인 행사` D+1 복습을 완료했다. 현재 10일 구간의 빈도 상태와 나가는·들어오는 원소만 갱신해도 되는 이유를 회상했다.

## 풀이 후 새로 배운 점

### 프로세스

- 순서가 바뀌는 객체 중 하나를 계속 추적하려면 큐에 값과 원본 인덱스를 함께 저장한다.
- 큐는 아직 실행되지 않은 프로세스의 대기 순서, 최대 힙은 아직 실행되지 않은 우선순위 전체를 나타낸다.
- 복잡도가 제한을 만족한다는 설명과 알고리즘이 정답을 보장하는 이유는 별개의 설명이다.
- 현재 코드는 충분히 적절하다. `record Process(priority, index)`를 사용하면 `int[]`의 매직 인덱스를 없앨 수 있지만 이는 성능이 아니라 가독성 개선이다.

### 주식가격

- 각 시작점에서 미래를 반복 탐색하는 대신, 현재 값이 과거의 어떤 미확정 답을 확정하는지 관점을 반대로 바꿀 수 있다.
- 단조 스택에는 아직 가격 하락을 만나지 않은 인덱스를 저장한다. 현재 가격보다 큰 동안 꺼내 `현재 인덱스 - 이전 인덱스`로 지속 시간을 확정한다.
- 가격이 더 작은 원소가 들어오면 큰 가격은 즉시 제거되므로, 스택의 가격은 아래에서 위로 감소하지 않는 순서를 유지한다.
- 중첩 `while`이어도 각 인덱스가 한 번 들어가고 한 번 나오므로 전체 시간복잡도는 상환 `O(N)`이다.
- Codex가 작성한 최종 코드는 불필요한 보조 객체 없이 단조 스택을 `O(N)`으로 구현하고 있어 추가 클린 코드 재작성은 필요하지 않다.
