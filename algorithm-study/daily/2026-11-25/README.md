## 웹 편집기에서 막힌 문법·API

- `등굣길` — 웹 편집기에서 중간값을 확인하는 방법을 질문했다. 값이 바뀌는 줄 뒤에서 `System.out.println("i=" + i + ", j=" + j + ", dp=" + dp[i][j]);`를 실행해 최초로 예상과 다른 칸을 찾는다. 시작값은 첫 반복 전에 확인하고, 제출 전 확인용 출력은 제거한다.
- `PriorityQueue`를 선언하고 생성할 때 `cannot find symbol: class PriorityQueue`가 두 곳에서 발생했다. `class Solution` 위에 `import java.util.PriorityQueue;`를 추가하면 두 참조가 모두 해결된다. 표준 라이브러리 클래스에서 `cannot find symbol`이 뜨면 클래스 이름의 철자와 파일 상단의 `import`를 확인한다.
- `java.util` 클래스를 여러 개 쓸 때는 `import java.util.*;`로 가져올 수 있다. `java.util.stream`처럼 하위 패키지에 있는 클래스는 별도로 import한다.
- `Cannot load from int array because … is null`이면 `int[]` 원소를 읽는 줄 직전에 배열 참조를 출력한다. 값이 `peek()`나 `poll()`에서 왔다면 큐 크기도 함께 찍어 빈 상태에서 읽었는지 확인한다.
- `부대복귀` — Java import 누락을 제출 전에 수정했다. `List<Integer>`는 `list.stream().mapToInt(Integer::intValue).toArray()`로 `int[]`로 바꿀 수 있다. 결과 길이가 미리 정해져 있다면 처음부터 `int[]`에 채워도 된다.
- MySQL `1064` — `at line N`으로 줄을 찾고 `near` 바로 뒤 토큰과 그 직전에 쓴 내용을 읽는다. `near 'THEN ...'`이면 `CASE WHEN 조건 THEN 값 ELSE 값 END` 문법부터 확인한다.
- MySQL 기간 계산은 `DATEDIFF(종료일, 시작일)` 순서다. 두 날짜를 모두 대여일로 세면 `+ 1`이 필요하다. 9월 1일~30일은 날짜 차이 29일, 포함 일수 30일이다.

### 시험 전 보완 우선순위

1. **첫 실행에 작은 경계 입력 하나를 추가한다.** 시뮬레이션은 만료 직전과 만료 시각, 경로 수는 출발점과 첫 이동, SQL은 분류 기준 바로 아래인 29일과 기준인 30일을 확인한다. 웹 편집기에서는 현재 시각·기대값·실제값을 한 줄로 찍어 첫 차이를 찾는다.

3. **SQL은 결과 한 행에 무엇을 요약할지 문장으로 적는다.** 기준일 상태 문제의 출력 단위는 차량이고 판단 단위는 대여 기록이다. 기록마다 날짜 포함 여부를 판단하고 차량별로 하나라도 해당하는지 집계한다.

### 프렌즈4블록 재도전 B등급 D+1 이월

코드 없이 다음을 3분 안에 설명한다.

1. 한 턴의 삭제 대상을 찾는 중에 보드를 바로 바꾸면 안 되는 이유
2. 열 하나를 아래에서부터 채울 때 각 블록을 한 번씩만 옮겨도 되는 이유

**부분 완료.** 겹치는 2×2 묶음의 판정에 영향이 간다는 점을 설명했다. 열 압축은 아래부터 읽으면서 살아 있는 블록을 아래쪽의 다음 자리 `writeRow`에 쓴다. 쓰는 위치는 현재 읽는 칸과 같거나 더 아래라서, 위쪽에서 아직 읽지 않은 블록은 그대로 남는다. 이 근거는 기존 D+3 회상에 포함한다.

### 행렬 테두리 회전하기 A등급 D+3 이월

코드 없이 다음을 3분 안에 설명한다.

1. 값 하나를 미리 보관하지 않으면 어느 값이 사라지는가?
2. 네 변을 어떤 순서로 옮겨야 아직 사용하지 않은 값을 덮어쓰지 않는가?

**완료.** 첫 대입에 덮이는 값을 보관하고, 각 변에서 값이 이동하는 방향의 반대로 순회한다는 원리를 설명했다. 리뷰 예시는 왼쪽 위 값을 저장한 뒤 왼쪽 변 → 아래 변 → 오른쪽 변 → 위쪽 변 순으로 채운다.

계획 기준으로 알고리즘 120분 + SQL 33분 + 복습 5~6분이다.
