- `피로도`는 최대 8개라는 제한에서 순열 탐색이 가능함을 판단하고, 8분 만에 방문 배열 백트래킹 설계를 확정해 24분에 첫 제출로 통과했다.

- SQL `흉부외과 또는 일반외과 의사 목록 출력하기`는 5분에 첫 제출로 통과했고 출력·필터·두 정렬 기준을 모두 정확히 반영했다. 전날의 `ORDER BY` 누락이 반복되지 않았다.
- 같은 컬럼의 여러 동등 비교는 현재처럼 `OR`로 작성해도 정확하며, `IN ('CS', 'GS')`으로 바꾸면 값 목록이라는 의도가 더 간결하게 드러난다.
- `모음사전`은 10분 만에 상태 공간 DFS를 설계하고 20분에 첫 제출로 통과했다. 모음 순서의 전위 DFS가 길이 5 이하 문자열을 실제 사전순으로 생성하므로 A등급이다.
- 오늘 두 알고리즘 문제를 통해 방문 배열이 필요한 순열 탐색과, 각 깊이에서 같은 문자를 다시 선택할 수 있는 문자열 상태 생성을 모두 독립적으로 구현했다.
