# Daily Records

날짜별로 `YYYY-MM-DD/문제명/` 폴더를 만들고 `문제명.java`와 `review.md`를 함께 저장합니다. Java 파일명과 `public class`는 공백을 밑줄로 바꾼 동일한 이름을 사용합니다.

`review.md`에는 Codex가 목표 시간과 단계별 배분을 미리 기록합니다. 사용자는 풀이 전 핵심 사고를 각 한두 문장으로 쓰고, 풀이 후 시간·결과·제출·힌트·설계·구현 기록만 짧게 남깁니다. Codex는 풀이 전 메모와 제출 코드를 비교해 놓친 신호, 의도와 다른 접근, 복잡도·자료구조·Java API·안전성 개선 중 중요한 학습점 1~3개를 원리와 함께 풀이 직후 설명합니다. 새로 배운 내용은 회고와 복습 일정에 기록하며, D+3에는 새로 공개하지 않고 두 접근을 회상·비교합니다.

하루 두 문제의 평가가 끝나면 날짜 폴더의 `README.md`에 문제 결과, 당일 평가, 복습 일정과 ChatGPT 전달용 `[Codex 학습 요약]`을 기록합니다.
