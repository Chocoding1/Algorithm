- 클린 코드 예시:

```java
import java.util.ArrayDeque;
import java.util.Queue;

public class 게임_맵_최단거리 {
    private static final int[][] DIRECTIONS = {
            {0, 1}, {1, 0}, {0, -1}, {-1, 0}
    };

    public int solution(int[][] maps) {
        int rows = maps.length;
        int cols = maps[0].length;
        int[][] distance = new int[rows][cols];
        Queue<int[]> queue = new ArrayDeque<>();

        queue.offer(new int[]{0, 0});
        distance[0][0] = 1;

        while (!queue.isEmpty()) {
            int[] current = queue.poll();
            int row = current[0];
            int col = current[1];

            if (row == rows - 1 && col == cols - 1) {
                return distance[row][col];
            }

            for (int[] direction : DIRECTIONS) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];

                if (nextRow < 0 || nextRow >= rows
                        || nextCol < 0 || nextCol >= cols
                        || maps[nextRow][nextCol] == 0
                        || distance[nextRow][nextCol] != 0) {
                    continue;
                }

                distance[nextRow][nextCol] = distance[row][col] + 1;
                queue.offer(new int[]{nextRow, nextCol});
            }
        }

        return -1;
    }
}
```

- 풀이 후 새로 배운 점: 가중치가 같은 그래프에서 BFS는 시작점과의 거리가 작은 순서로 정점을 꺼내므로 목적지를 처음 발견하거나 꺼낸 순간의 거리가 최단거리다. 방문 처리는 큐에 넣을 때 해야 같은 칸의 중복 삽입을 막는다.
- 다음 문제에 적용할 한 문장 규칙: 모든 이동 비용이 같고 최소 이동 횟수를 구하면, 상태를 정점으로 만들고 큐 삽입 시 방문 처리하는 BFS를 우선 검토한다.
- 복습에 포함할 학습 포인트: `O(N×M)`의 근거, 삽입 시 방문 처리 이유, 목적지를 처음 만난 거리가 최단거리인 이유
- 오류 분류: 없음
- 시간복잡도: `O(N×M)` — 각 칸이 최대 한 번 큐에 들어가고 각 칸에서 네 방향만 확인
- 공간복잡도: `O(N×M)` — 방문 정보와 최악의 경우 큐에 저장되는 위치
