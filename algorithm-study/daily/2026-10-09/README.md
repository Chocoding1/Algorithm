신규 알고리즘 문제의 핵심 유형·자료구조·목표 알고리즘과 복습 연결 관계는 풀이 완료 후 공개한다.

## 현재 평가

- `두 큐 합 같게 만들기`는 한 큐의 합을 목표와 비교해 앞 원소를 이동하는 `O(N)` 구현으로 최종 통과했다.
- 목표 시간을 25분 초과했고 진행 규칙과 `4N` 종료 조건을 핵심 힌트로 확인했으며 첫 제출에서 합계 `int` 오버플로로 런타임 오류가 발생해 C등급이다.
- 저장된 코드의 합계 변수는 `long`이지만 `Arrays.stream(int[]).sum()` 자체가 `int`로 계산되므로 `asLongStream().sum()`으로 바꿔야 제한 전체에서 안전하다. 원본 코드는 사용자 요청 없이 수정하지 않았다.
- 2026-10-11에 현재 코드·회고 없이 동일 문제를 재도전하고, 성공하면 2026-10-18에 새로운 변형으로 전이를 다시 확인한다.
- `특정 옵션이 포함된 자동차 리스트 구하기`는 `LIKE '%네비게이션%'`로 포함 조건을 적용하고 `CAR_ID` 내림차순까지 정확히 구현해 첫 제출로 통과했다.
- 풀이 중 문자열 포함 문법과 현재 컬럼 적용 예시를 확인했으므로 작은 힌트·B등급으로 기록한다. 2026-10-11 주간 혼합 SQL에서 `LIKE`를 독립 적용해 전이를 확인한다.
- `게임 맵 최단거리`는 7분 만에 격자 BFS 설계를 확정하고 27분에 첫 제출로 통과했다. 각 칸을 큐에 넣을 때 방문 처리해 `O(N×M)`을 보장했으므로 A등급이다.
- 2026-10-12에 BFS가 최단거리를 보장하는 이유와 방문 처리 시점을 짧게 회상하고, 2026-10-16에 유형 비공개 격자 탐색 변형으로 전이를 확인한다.
