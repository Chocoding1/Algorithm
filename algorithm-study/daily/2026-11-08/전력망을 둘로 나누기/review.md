## Codex 분석

- 힌트 수준(Codex 판정): 핵심 힌트
- 힌트 판정 근거: 전선을 하나씩 제외하는 전체 방향은 사용자가 독립적으로 세웠지만, 미방문 정점으로 이동해야 한다는 방문 조건, 경로 깊이가 아닌 방문 정점 총수를 세어야 한다는 상태 정의, `count`와 `n-count`의 차이를 계산해야 한다는 핵심 식을 Codex가 직접 특정했다.
- 복습 등급: C
- 등급 판정 근거: 최종 성공했고 공식 제출은 첫 제출로 통과했지만 목표 35분을 25분 초과했으며, 정답을 결정하는 방문 상태·개수 집계·최종 차이 계산에 핵심 힌트를 사용했다.
- 목표 시간 달성: 미달성 — 35분 목표, 실제 60분
- 첫 시도 성공: 공식 제출 기준 성공 — 로컬 오답을 수정한 뒤 첫 공식 제출 통과
- 공식 출제 의도 알고리즘: 모든 전선을 한 번씩 끊어 보고 DFS 또는 BFS로 한쪽 전력망의 송전탑 수를 계산하는 완전탐색
- Codex 추천 목표 알고리즘: 인접 리스트를 한 번 만든 뒤, 제외할 전선마다 방문 배열을 초기화하고 한쪽 연결 요소의 크기를 세는 DFS
- 실제 풀이와 의도 알고리즘 비교: 일치. 전선 후보를 전부 확인하고, 제외한 전선을 건너뛰며 1번 송전탑에서 도달 가능한 송전탑 수를 계산했다.
- 풀이 전 사고와 실제 코드의 차이: 간선을 제외하고 재귀 탐색한다는 설계는 유지됐다. 다만 최초 구현은 미방문 정점을 건너뛰었고, 최대 재귀 깊이를 송전탑 수로 오해했으며, 최종적으로 두 전력망의 크기가 아닌 `n`과 한쪽 크기를 비교했다.
- 코드 개선 포인트: `totalCount` 전역 변수와 탐색 후 방문 해제를 없애고, DFS가 현재 정점에서 연결된 송전탑 수를 반환하게 만들면 상태의 의미가 명확해진다. 후보 전선마다 새 방문 배열을 만들면 각 탐색의 독립성도 코드에 드러난다. 빅오는 동일하고 가독성·안전성 개선이다.
- 풀이 후 새로 배운 점: 재귀 호출의 최대 깊이는 방문한 전체 정점 수가 아니다. 가지가 나뉘는 그래프의 크기는 새 정점을 처음 방문할 때마다 1씩 합산하거나 DFS 반환값을 합쳐 계산해야 한다.
- 다음 문제에 적용할 한 문장 규칙: 그래프에서 개수를 구할 때는 `재귀 깊이`인지 `방문한 전체 정점 수`인지 먼저 구분하고, 정답식에 들어갈 두 값을 각각 이름으로 적는다.
- 복습에 포함할 학습 포인트: 방문 조건의 방향, DFS 반환값으로 연결 요소 크기 계산, 한쪽 크기가 `count`일 때 차이가 `|count-(n-count)| = |2*count-n|`인 이유, 전선별 DFS가 `O(N²)`인 이유
- 오류 분류: 설계·구현·시간 관리
- 시간복잡도: 전선 `N-1`개마다 최대 `N`개 정점과 `N-1`개 간선을 탐색하므로 `O(N²)`
- 공간복잡도: 인접 리스트·방문 배열·최악의 재귀 깊이를 합쳐 `O(N)`

### 클린 코드 예시

원본과 같은 `O(N²)` 풀이이며, 전역 카운터 대신 DFS 반환값으로 연결 요소의 크기를 표현한 가독성·안전성 개선이다. 사용자 원본 Java에는 적용하지 않는다.

```java
import java.util.ArrayList;
import java.util.List;

public class Solution {

    private List<Integer>[] network;
    private boolean[] visited;

    public int solution(int n, int[][] wires) {
        network = new ArrayList[n + 1];
        for (int tower = 1; tower <= n; tower++) {
            network[tower] = new ArrayList<>();
        }

        for (int[] wire : wires) {
            network[wire[0]].add(wire[1]);
            network[wire[1]].add(wire[0]);
        }

        int answer = n;

        for (int[] removedWire : wires) {
            visited = new boolean[n + 1];
            int connectedCount = countConnectedTowers(1, removedWire);
            answer = Math.min(answer, Math.abs(n - 2 * connectedCount));
        }

        return answer;
    }

    private int countConnectedTowers(int current, int[] removedWire) {
        visited[current] = true;
        int count = 1;

        for (int next : network[current]) {
            if (visited[next] || isRemoved(current, next, removedWire)) {
                continue;
            }
            count += countConnectedTowers(next, removedWire);
        }

        return count;
    }

    private boolean isRemoved(int from, int to, int[] removedWire) {
        return removedWire[0] == from && removedWire[1] == to
                || removedWire[0] == to && removedWire[1] == from;
    }
}
```
