## Java 알고리즘 2문제

### 1. 입국심사 재도전

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/43238?language=java
- 플랫폼 / 난이도: 프로그래머스 Lv.3
- 목표 시간: 35분
- 추천 이유: 11월 2일에 정답 코드까지 확인한 C등급 문제의 독립 재현을 검증한다. 이전 코드·회고·대화는 열지 않고 처음부터 구현한다.
- 확인 질문:
  - 최대 입력에서 사람을 한 명씩 배정하거나 시간을 한 단위씩 진행하는 방식이 가능한가?
  - 선택한 방법은 매 반복에서 무엇을 확인하고 다음 후보를 어떻게 줄이는가?
  - 반복이 끝났을 때 반환값이 가능한 값 중 최소라는 것을 어떻게 확인할 수 있는가?
- 결과: 실제 완료일 2026-11-09, 15분, 첫 공식 제출 통과
- 복습 등급: A — 이전 자료와 추가 힌트 없이 7분에 설계를 확정하고 독립 재현
- 실제 풀이: 시간별 처리 가능 인원의 단조성을 이용해 처음 가능한 시간을 찾는 `O(M log T)` 이분 탐색
- 주요 학습점: 가능한 `mid`는 정답일 수 있어 `right = mid`로 유지하고, 불가능한 `mid`만 `left = mid + 1`로 제외한다.
- 복습 일정: 2026-11-12 짧은 회상, 2026-11-16 유형 비공개 변형

### 2. 전력망을 둘로 나누기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/86971?language=java
- 플랫폼 / 난이도: 프로그래머스 Lv.2
- 목표 시간: 35분
- 추천 이유: 제한된 입력에서 한 번의 변경으로 달라지는 결과를 빠짐없이 비교하고, 구현 전에 정답 조건을 분명히 정의하는 연습을 한다.
- 확인 질문:
  - 전선 하나를 끊었을 때 최종적으로 비교해야 하는 두 값은 무엇인가?
  - 입력 크기에서 가능한 선택을 각각 확인하는 방식은 어느 정도의 연산량까지 허용되는가?
  - 최소 입력과 정확히 반으로 나뉘는 경우에도 같은 반환 규칙이 성립하는가?
- 결과: 실제 완료일 2026-11-09, 60분, 로컬 오답 수정 후 첫 공식 제출 통과
- 복습 등급: C — 방문 조건·송전탑 개수 집계·최종 차이 계산에 핵심 힌트 사용
- 실제 풀이: 모든 전선을 하나씩 제외하고 DFS로 한쪽 전력망의 송전탑 수를 계산하는 `O(N²)` 완전탐색
- 주요 학습점: 재귀 깊이와 전체 방문 정점 수를 구분하고, 두 전력망의 크기를 각각 적은 뒤 차이를 계산한다.
- 복습 일정: 2026-11-11 동일 문제 독립 재도전, 성공하면 2026-11-18 유형 비공개 변형
