## 오늘의 평가

- `주식가격`은 최초 C등급 이후 이전 코드·해설을 보지 않고 5분 만에 단조 스택 설계를 다시 만들어 20분에 통과했다.
- 이어서 처음 푼 `뒤에 있는 큰 수 찾기`에서도 7분 만에 반대 비교 조건의 단조 스택을 설계해 13분에 첫 제출로 통과했다. 학습한 구조를 새 문제에 즉시 적용하는 전이는 성공했다.
- 두 알고리즘 문제 모두 복잡도 근거는 설명했지만, 스택에 남은 인덱스의 의미와 현재 값이 첫 조건 충족 원소인 이유를 정답 근거로 분리해 설명하는 연습이 필요하다.
- 첫 SQL 문제는 4분에 첫 제출로 통과했다. 결과 한 행과 중복·NULL 개념도 이해하고 있었으며, 기존 회고 질문이 행 번호를 묻는 것처럼 모호해 답변에 드러나지 않았던 것으로 확인해 A등급으로 정정했다.

## 풀이 후 새로 배운 점

### 단조 스택

- 오른쪽의 첫 조건 만족 원소를 찾을 때, 현재 값이 과거의 미확정 인덱스 여러 개를 확정할 수 있는지 확인한다.
- 각 원소가 한 번 push·pop된다는 설명은 `O(N)` 복잡도의 근거다. 스택 불변식과 “왜 현재 값이 첫 정답인가”는 별도의 정답성 근거다.
- 입력 배열에서 값을 다시 읽을 수 있으면 스택에는 인덱스만 저장해 상태와 객체 생성을 줄일 수 있다.

### SQL

- 추가 학습 항목은 없다. 현재 쿼리와 개념 이해는 충분했다.
- 회고 질문을 `FROM`에서 읽는 테이블, 데이터 한 건의 의미, SQL 절 전후의 행 변화가 드러나도록 수정했다.
