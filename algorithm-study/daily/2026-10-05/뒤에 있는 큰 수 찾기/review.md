## Codex 분석

- 복습 등급: B
- 등급 판정 근거: 목표 30분 안인 13분에 힌트 없이 첫 제출로 통과했고, 구현 실수 없이 7분 만에 `O(N²)` 병목을 단조 스택 `O(N)` 설계로 바꿨다. 다만 사용자가 적은 정답 근거는 각 원소가 스택에 한 번 들어가고 나오는 복잡도 근거이며, 현재 값이 꺼낸 인덱스의 **오른쪽 첫 큰 수**임을 보장하는 스택 불변식 설명은 빠져 있어 A등급의 정확성 설명 조건을 충족하지 못했다.
- 목표 시간 달성: 달성 (13분 / 30분)
- 첫 시도 성공: 성공 (첫 제출 통과)

- Codex 추천 목표 알고리즘: 오른쪽의 첫 큰 수를 미확정 인덱스 단조 스택으로 `O(N)`에 확정
- 공식 의도 일치 여부: 공식 의도 명시 없음
- Codex 목표 일치 여부: 일치
- 실제 풀이와 의도 알고리즘 비교: 사용한 풀이가 Codex 목표와 같다. 스택에는 아직 오른쪽에서 더 큰 수를 만나지 못한 인덱스만 남기고, 현재 값이 스택 위 인덱스의 값보다 클 때 그 인덱스의 답을 현재 값으로 확정했다.
- 풀이 전 사고와 실제 코드의 차이: 메모에는 값과 인덱스를 함께 저장한다고 적었지만 실제 코드는 인덱스만 저장하고 `numbers[index]`로 값을 조회해 상태 중복을 피했다. 설계의 핵심 흐름은 그대로 구현했다.
- 의도 알고리즘 추가 학습 이유: 다른 알고리즘 학습은 필요 없다. 이번에는 복잡도와 별개인 단조 스택의 정답성 불변식을 보완하면 된다.
- 풀이 직후 확인한 의도 알고리즘: 현재 풀이와 동일한 미확정 인덱스 단조 스택
- 대안 학습 상태: 불필요
- 코드 개선 포인트: 알고리즘과 점근 복잡도는 이미 최적이다. `Deque<Integer>` 인터페이스로 역할을 드러내고, 정답 배열을 처음부터 `-1`로 채우면 마지막 미확정 인덱스 제거 반복문을 없앨 수 있다. `Integer` 지역 변수는 `int`로 받아도 된다. 이는 빅오 개선이 아니라 가독성 개선이다.
- 클린 코드 예시:

```java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

public int[] solution(int[] numbers) {
    int[] answer = new int[numbers.length];
    Arrays.fill(answer, -1);
    Deque<Integer> stack = new ArrayDeque<>();

    for (int current = 0; current < numbers.length; current++) {
        while (!stack.isEmpty()
                && numbers[stack.peek()] < numbers[current]) {
            int previous = stack.pop();
            answer[previous] = numbers[current];
        }
        stack.push(current);
    }

    return answer;
}
```

- 풀이 후 새로 배운 점: 스택에는 답이 아직 정해지지 않은 인덱스가 남고, 스택의 값은 아래에서 위로 갈수록 증가하지 않는 단조 상태를 이룬다. 현재 값보다 작은 인덱스를 꺼낼 때, 그 사이에서 더 큰 값을 만났다면 이미 앞서 꺼졌어야 하므로 현재 값이 그 인덱스가 처음 만난 오른쪽 큰 수다. 현재 값 이상인 스택 위 원소를 만나면 더 아래 원소도 현재 값보다 작지 않으므로 탐색을 멈춰도 된다.
- 다음 문제에 적용할 한 문장 규칙: 각 원소의 답이 미래의 첫 조건 충족 원소에서 확정되고 반복적인 오른쪽 탐색이 생기면, 답이 미확정인 인덱스를 단조 스택에 유지한다.
- 복습에 포함할 학습 포인트: 복잡도 증명과 정답성 증명을 분리하고, 스택에 무엇이 남아 있는지·왜 현재 값이 첫 정답인지·동일한 값에서 왜 pop하지 않는지를 설명한다.
- 오류 분류: 없음 (정확성 설명 보완)
- 잘한 점: 최대 1,000,000이라는 제한에서 `O(N²)`가 불가능함을 바로 판단했고, 7분 만에 단조 스택 설계를 확정해 13분에 첫 제출로 통과했다. `주식가격`에서 학습한 미확정 인덱스 관점을 새 문제의 반대 비교 조건에 독립적으로 적용했다.
- 개선할 점: “각 원소가 한 번 push/pop된다”는 말은 `O(N)`의 근거다. 정답 보장에는 스택 불변식과 현재 값이 첫 큰 수인 이유를 별도로 설명해야 한다.
- 유형 인식 신호: 각 위치에서 오른쪽의 첫 조건 충족 원소를 찾고, 단순 풀이가 같은 오른쪽 구간을 반복 탐색한다.
- 다음에 적용할 규칙: 스택에 미확정 인덱스를 넣고, 현재 원소가 스택 위 인덱스의 답을 확정하는 동안만 pop한다.
- 시간복잡도: `O(N)` — 각 인덱스는 한 번 push되고 최대 한 번 pop된다.
- 공간복잡도: `O(N)` — 정답 배열과 최악의 경우 모든 인덱스를 담는 스택이 필요하다.
