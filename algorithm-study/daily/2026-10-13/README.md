`모의고사` A등급 D+7은 선택 복습이므로, 오늘은 C등급 재도전과 현재 압축 진도를 우선해 생략한다.

## 중간 평가

- `괄호 회전하기` 재도전은 이전 코드·회고 없이 3분에 설계를 확정하고, 회전 인덱스와 종료 후 빈 스택 조건을 독립 재현해 첫 제출로 통과했다.
- 25분 목표보다 5분 늘어났고 `peek()`과 `peekLast()`를 혼동했으므로 재도전 등급은 B다. 동일 문제 재도전은 완료했고 10월 20일 신규 변형으로 이어간다.
- 원본 Java는 수정하지 않았고, `switch`와 `isValid`로 성공 조건을 분리한 클린 코드 예시는 문제별 `review.md`에 기록했다.
- SQL `고양이와 개는 몇 마리 있을까`는 종류별 그룹 집계는 정확했지만, `GROUP BY`가 순서를 보장한다고 가정해 고양이 우선 정렬을 누락했다. 오답 1회 후 완성 쿼리를 확인했으므로 C등급이며 10월 15일에 동일 문제를 5분 이내 재도전한다.
- SQL `진료과별 총 예약 횟수 출력하기`는 `SELECT`·날짜 필터·그룹 집계·다중 정렬의 핵심 구조를 스스로 구성했지만, 별칭 인용과 날짜 범위 문법을 질문하는 과정에서 완성 쿼리를 확인했다. 15분에 오답 1회 후 통과했으며 C등급으로 기록하고 10월 16일에 이전 자료 없이 5분 이내 재도전한다.
- `타겟 넘버`는 5분에 DFS 설계를 확정하고 15분에 힌트·구현 실수 없이 첫 제출로 통과해 A등급이다. 각 숫자에서 `+`·`-` 두 경로를 전부 탐색하는 실제 시간복잡도는 `O(2^N)`이며, 문자열 연산과 전역 상태를 없앤 반환형 DFS 클린 코드를 문제별 `review.md`에 기록했다. 10월 16일에는 상태 정의·정답성·복잡도만 2~3분 회상한다.
- 이월됐던 `네트워크` D+1 복습도 완료했다. 바깥 반복문의 번호순 처리와 DFS의 이동 순서는 별개이며, `0-2-1`처럼 높은 번호에서 낮은 미방문 정점으로 이어지는 경로 때문에 인접 행렬의 모든 열을 확인해야 함을 설명했다.
