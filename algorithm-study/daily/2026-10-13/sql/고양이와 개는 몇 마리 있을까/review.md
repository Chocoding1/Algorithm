## Codex 분석

- 힌트 수준(Codex 판정): 정답 쿼리 — `ORDER BY ANIMAL_TYPE`을 포함한 완성 쿼리를 제공함
- 복습 등급: C
- 등급 판정 근거: 20분 목표 내 5분에 그룹 단위 집계는 정확히 구현했지만, 고양이를 먼저 출력하는 정렬 조건을 누락해 오답 1회 후 완성 쿼리를 확인함
- 목표 시간 달성: 예 (5분 / 20분)
- 첫 시도 성공: 아니오 (첫 통과 전 오답 1회)
- 핵심 문법: `GROUP BY`, `COUNT`, `ORDER BY`
- 결과 한 행의 단위: 한 동물 종류와 그 종류에 포함된 입소 동물 수
- 쿼리 데이터 흐름: `FROM ANIMAL_INS`의 동물 한 마리씩을 `GROUP BY ANIMAL_TYPE`으로 종류별 한 행으로 축약하고, `COUNT`로 그룹의 동물 수를 구한 뒤 `ORDER BY ANIMAL_TYPE`으로 `Cat`을 `Dog`보다 먼저 배치함
- 중복·NULL·JOIN 카디널리티 확인: `ANIMAL_TYPE`은 `NULL` 불가 컬럼이므로 `COUNT(ANIMAL_TYPE)`과 `COUNT(*)`의 결과는 같다. JOIN이 없으므로 원본 행이 증가하지 않는다.
- 정답 검증: 실행 결과는 나왔지만 정렬 미지정으로 첫 제출 실패, `ORDER BY` 추가 후 프로그래머스 통과
- 코드 개선 포인트: **정확성·가독성 개선** — 현재 집계는 정확하다. `COUNT(*) AS count`로 그룹의 행 수를 세는 의도와 출력 열 이름을 명확히 표현할 수 있다.
- 클린 쿼리 예시:

```sql
SELECT ANIMAL_TYPE, COUNT(*) AS count
FROM ANIMAL_INS
GROUP BY ANIMAL_TYPE
ORDER BY ANIMAL_TYPE;
```

- 풀이 후 새로 배운 점: `GROUP BY`는 결과 그룹의 출력 순서를 보장하지 않으므로, 요구된 순서는 반드시 `ORDER BY`로 명시해야 한다.
- 오류 분류: 정렬·출력 요구사항 누락
- 다음에 적용할 규칙: **실행 결과의 현재 순서를 신뢰하지 말고, 문제가 순서를 요구하면 `ORDER BY`를 명시한다.**
