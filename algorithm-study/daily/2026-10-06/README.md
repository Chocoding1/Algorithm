## 현재 평가

- `모의고사`는 5분 만에 반복 패턴의 직접 비교 설계를 확정하고 목표 시간 안에 첫 제출로 통과했다.
- 서로 길이가 다른 패턴을 `int[][]`와 나머지 연산으로 정확하게 순환시켰으며 시간복잡도는 `O(N)`이다.
- 결과 번호를 이미 오름차순으로 순회하므로 별도 정렬은 필요 없다. 이는 빅오 변화 없이 중간 객체와 불필요한 연산을 줄이는 개선이다.
- `어린 동물 찾기`는 5분에 첫 제출로 통과했지만, 풀이 전에는 확인했던 ID 정렬을 실제 쿼리에서 빠뜨렸다. `ORDER BY`가 없으면 반환 순서는 보장되지 않으므로 정확성 누락으로 기록했다.
- SQL 비교식에서 `NULL <> 'Aged'`는 참이 아니라 `UNKNOWN`이 되어 `WHERE`에서 제외된다. NULL을 포함하려는 요구라면 `IS NULL` 조건이 별도로 필요하다.
- `최소직사각형`은 긴 변과 짧은 변을 같은 방향으로 정규화하는 핵심 기준을 힌트로 확인한 뒤 첫 제출로 통과했다. 핵심 힌트를 사용했으므로 C등급이며 10월 8일 동일 문제를 독립 재도전한다.
- 구현의 내부 반복문은 같은 교환 조건을 두 번 확인한다. `Math.max`·`Math.min`으로 각 명함을 해석하면서 두 최댓값을 동시에 갱신하면 입력을 바꾸지 않고 한 번의 순회로 표현할 수 있다.
- `뒤에 있는 큰 수 찾기` D+1 복습은 아직 완료 기록 전이다.
