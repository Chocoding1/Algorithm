## Codex 분석

- 힌트 수준(Codex 판정): 없음
- 복습 등급: A
- 등급 판정 근거: 목표 40분 안인 13분에 성공했고 2분 만에 설계를 확정했으며, 힌트·구현 실수 없이 BFS 거리 계산을 첫 제출로 통과했다.
- 목표 시간 달성: 달성 — 40분 목표, 실제 13분
- 첫 시도 성공: 성공 — 첫 공식 제출 통과
- 공식 출제 의도 알고리즘: 공식 의도 명시 없음. 모든 간선의 비용이 동일하므로 일반적으로 BFS로 1번 노드의 최단거리를 계산한다.
- Codex 추천 목표 알고리즘: 인접 리스트와 일반 큐를 사용해 최초 도달 거리를 저장하고 최댓값과 같은 거리의 노드 수를 집계하는 BFS
- 실제 풀이와 의도 알고리즘 비교: Codex 목표와 일치. 큐에 노드와 거리를 넣고 더 짧은 거리로 처음 갱신되는 노드만 추가해 각 노드의 최단거리를 계산했다.
- 풀이 전 사고와 실제 코드의 차이: 풀이 전에는 모든 이동 경로를 만들 수 있을 수도 있다고 판단했지만, 실제 구현에서는 각 노드를 더 짧은 거리로 갱신할 때만 큐에 넣어 경로 열거 없이 해결했다. 모든 단순 경로를 나열하면 경우의 수가 지수적으로 늘 수 있고, 방문 제한이 없으면 순환 그래프에서 이동 경로가 끝없이 생성될 수 있다.
- 코드 개선 포인트: 큐에 현재 거리를 함께 저장하지 않고 노드 번호만 저장한 뒤 `dist[current]`를 읽어도 된다. `dist`의 초기값을 `-1`로 두면 미방문 여부까지 함께 표현할 수 있어 별도의 큰 상수 비교가 사라진다. 빅오는 동일하고 가독성·메모리 상수 개선이다.
- 풀이 후 새로 배운 점: 모든 간선의 이동 비용이 같으면 큐의 레벨 순서가 거리 순서와 같아 최초 도달이 최단거리다. 같은 날 `배달`처럼 비용이 다르면 일반 큐의 최초 도달을 최솟값으로 확정할 수 없어 누적 비용 순서가 필요하다.
- 다음 문제에 적용할 한 문장 규칙: 최단거리 문제를 보면 먼저 모든 간선 비용이 같은지 확인하고, 같으면 일반 큐의 최초 도달 거리, 다르면 비용이 작은 후보를 우선하는 방법을 고려한다.
- 복습에 포함할 학습 포인트: 모든 경로 열거의 지수적 증가, 큐의 레벨 순서가 최단거리를 보장하는 이유, `dist`를 방문 상태로 함께 사용하는 방법, BFS `O(V+E)` 근거
- 오류 분류: 없음
- 시간복잡도: 노드 수를 `V`, 간선 수를 `E`라 하면 각 노드와 양방향 간선을 한 번씩 처리하므로 `O(V+E)`
- 공간복잡도: 인접 리스트·거리 배열·큐를 합쳐 `O(V+E)`

### 클린 코드 예시

원본과 같은 BFS이며, 큐에는 노드 번호만 저장하고 `distance == -1`을 미방문 상태로 사용한다. 빅오 개선은 없고 상태 표현과 가독성을 단순화한 예시이며 원본 Java에는 적용하지 않는다.

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Queue;

public class Solution {

    public int solution(int n, int[][] edge) {
        List<Integer>[] graph = new ArrayList[n + 1];
        for (int node = 1; node <= n; node++) {
            graph[node] = new ArrayList<>();
        }

        for (int[] connection : edge) {
            graph[connection[0]].add(connection[1]);
            graph[connection[1]].add(connection[0]);
        }

        int[] distance = new int[n + 1];
        Arrays.fill(distance, -1);
        distance[1] = 0;

        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(1);

        int maxDistance = 0;

        while (!queue.isEmpty()) {
            int current = queue.poll();

            for (int next : graph[current]) {
                if (distance[next] != -1) {
                    continue;
                }

                distance[next] = distance[current] + 1;
                maxDistance = Math.max(maxDistance, distance[next]);
                queue.offer(next);
            }
        }

        int answer = 0;
        for (int node = 1; node <= n; node++) {
            if (distance[node] == maxDistance) {
                answer++;
            }
        }
        return answer;
    }
}
```
