## Java 알고리즘 2문제

### 1. 가장 먼 노드

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/49189?language=java
- 플랫폼 / 난이도: 프로그래머스 Lv.3
- 목표 시간: 40분
- 추천 이유: 큰 입력에서 1번 노드와 다른 노드들의 관계를 효율적으로 계산하고, 최종적으로 요구되는 노드 수를 정확히 집계하는 연습을 한다.
- 확인 질문:
  - 노드와 간선의 최댓값에서 가능한 모든 이동 경로를 직접 나열할 수 있는가?
  - 같은 노드에 여러 경로로 도달할 수 있을 때 어떤 값만 결과 계산에 필요할까?
  - 가장 멀리 떨어진 노드가 여러 개일 때 모두 빠짐없이 세었다고 어떻게 확인할 수 있을까?
- 결과: 13분, 설계 2분, 첫 공식 제출 통과
- 복습 등급: A — 힌트·구현 실수 없이 일반 큐로 무가중 최단거리를 독립 구현
- 실제 풀이: 1번 노드에서 BFS로 최초 도달 거리를 저장하고 가장 큰 거리와 같은 노드 수를 집계
- 주요 학습점: 모든 경로를 나열하면 지수적으로 증가할 수 있지만, 모든 간선 비용이 같으면 큐의 최초 도달이 최단거리라 각 노드와 간선을 한 번씩만 처리한다.
- 복습 일정: 2026-11-12에 `배달`과 처리 순서 차이를 2~3분 비교, 별도 D+7은 이번 주 그래프 신규 진도에 흡수

### 2. 배달

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12978?language=java
- 플랫폼 / 난이도: 프로그래머스 Lv.2
- 목표 시간: 45분
- 추천 이유: 여러 이동 후보와 서로 다른 소요 시간이 함께 주어질 때, 각 마을에 도달하는 결과를 제한 안에서 안정적으로 계산하는 연습을 한다.
- 확인 질문:
  - 같은 두 마을을 잇는 도로가 여러 개일 때 어떤 이동 시간이 결과에 영향을 주는가?
  - 1번 마을에서 각 마을까지 가능한 모든 경로를 나열하면 연산량이 어떻게 늘어나는가?
  - 정확히 `K`시간이 걸리는 마을과 중간 마을을 거쳐 더 빨라지는 경우를 모두 포함한다고 어떻게 검증할 수 있을까?
- 결과: 39분 30초, 설계 13분, 첫 공식 제출 통과
- 복습 등급: A — 풀이 힌트 없이 우선순위 큐 기반 최소 시간 탐색을 독립 구현
- 실제 풀이: 누적 시간이 가장 작은 후보부터 마을을 확정하고 `K` 이내 경로만 확장하는 최단거리 탐색
- 주요 학습점: 모든 도로 시간이 양수이므로 마을이 우선순위 큐에서 처음 꺼내질 때 그 누적 시간이 최소이며, 거리 배열을 사용하면 더 느린 중복 후보를 줄일 수 있다.
- 복습 일정: 2026-11-12 짧은 회상, 2026-11-16 유형 비공개 변형

두 문제 모두 목표 시간의 60%까지 구현 가능한 설계가 없으면 막힌 지점을 적고 작은 힌트를 요청한다. `가장 먼 노드`는 24분, `배달`은 27분이 힌트 판단 시점이다.

## MySQL SQL 2문제

### 1. 대여 기록이 존재하는 자동차 리스트 구하기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/157341
- 난이도: 프로그래머스 SQL Lv.3
- 오늘 연습 범주: 관계의 존재 여부·`EXISTS`·1:N 관계의 중복·날짜 범위
- 목표 시간: 20분
- 결과: 11분, 첫 통과 전 오답 3회
- 복습 등급: C — 날짜 리터럴과 1:N 중복 수정이 포함된 완성 쿼리를 확인한 뒤 통과
- 실제 풀이: `INNER JOIN` 후 `DISTINCT`로 자동차 ID 중복 제거
- 주요 학습점: 날짜 값은 작은따옴표로 감싸고, 존재 여부만 필요하면 `EXISTS`로 자동차 한 행을 유지할 수 있다.
- 복습 일정: 2026-11-11 현재 쿼리·회고 없이 `EXISTS` 방식으로 동일 문제 재도전

### 2. 업그레이드 할 수 없는 아이템 구하기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/273712
- 난이도: 프로그래머스 SQL Lv.3
- 오늘 연습 범주: 관계의 부재·`NOT EXISTS`·자기 참조 관계·정렬
- 목표 시간: 20분
- 결과: 15분, 첫 통과 전 오답 3회
- 복습 등급: C — `NOT IN`의 NULL 영향을 놓쳐 완성 쿼리를 확인한 뒤 통과
- 실제 풀이: 부모 아이템 ID 목록에서 `NULL`을 제외하고, 해당 목록에 포함되지 않은 아이템을 `NOT IN`으로 선택
- 주요 학습점: `NOT IN`의 서브쿼리가 `NULL`을 반환하면 비교가 `UNKNOWN`이 될 수 있으며, 관계의 부재는 `NOT EXISTS`로 더 직접적이고 NULL에 안전하게 표현할 수 있다.
- 복습 일정: 2026-11-12 현재 쿼리·회고 없이 `NOT EXISTS` 방식으로 동일 문제 재도전

SQL 두 문제의 합계 목표는 40분이다. 두 번째 문제에서 20분 동안 진전이 없으면 현재 쿼리와 막힌 지점을 저장하고 다음 학습일 재도전 후보로 넘긴다.
