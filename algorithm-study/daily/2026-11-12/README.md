# 2026-11-12 학습

어제 학습한 알고리즘 C등급 문제는 풀이 기억이 가라앉을 시간을 확보하기 위해 오늘 바로 재도전하지 않았다. Java 신규 문제 1개와 SQL 재도전 1개·신규 문제 1개를 진행했다.

## Java 알고리즘 1문제

### 1. 땅따먹기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12913
- 플랫폼 / 난이도: 프로그래머스 Lv.2
- 목표 시간: 35분
- 60% 힌트 판단 시점: 21분
- 추천 이유: 이번 주 신규 진도 중 아직 빈 영역을 보완한다. 행이 많아져도 제약을 지키며 최대 결과를 구할 수 있는 처리 흐름을 스스로 설계하는지 확인한다.
- 진행 결과: 실패 — 1시간 30분, 미제출, 정답 코드 확인으로 C등급. 누적 상태와 현재 행 상태를 분리하는 DP 전이를 학습했으며 11월 17일에 이전 코드를 보지 않고 재도전한다.
- 풀이 전 확인:
  - 모든 선택 순서를 직접 만들면 `N = 100,000`일 때도 가능한가?
  - 한 행의 선택이 다음 행에서 금지하는 선택은 정확히 무엇인가?
  - 행이 하나인 경우와 같은 열에 큰 값이 반복되는 경우를 검증했는가?

## MySQL SQL 2문제

### 1. 업그레이드 할 수 없는 아이템 구하기 재도전

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/273712
- 난이도: 프로그래머스 SQL Lv.3
- 오늘 연습 범주: `NOT EXISTS`·상관 서브쿼리·NULL 안전성
- 목표 시간: 15분
- 추천 이유: `NOT IN`의 NULL 영향으로 정답 쿼리를 확인했던 C등급 문제를 이전 쿼리 없이 재현한다.
- 진행 결과: 완료 — 7분, 첫 공식 제출 통과, B등급. `NOT IN`의 `NULL` 안전성은 재현했고 잘못된 `EXISTS` 조건 방향은 11월 15일 짧게 복습한다.

### 2. 조회수가 가장 많은 중고거래 게시판의 첨부파일 조회하기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/164671
- 난이도: 프로그래머스 SQL Lv.3
- 오늘 연습 범주: 서브쿼리·JOIN·문자열 결합·다중 정렬
- 목표 시간: 30분
- 추천 이유: 서브쿼리로 특정 게시물을 선택한 뒤 연결된 여러 행을 유지하며 출력 문자열을 조립하는 연습을 한다.
- 진행 결과: 완료 — 6분, 첫 통과 전 오답 3회, B등급. 최고 조회수 선택과 JOIN은 정확했고 `CONCAT()` 문자열 조립 문법을 새로 학습했다.

## 짧은 복습 — 총 5~8분

- `전력망을 둘로 나누기` D+1: 한쪽 연결 요소의 크기만 구하면 다른 쪽을 `n - count`로 알 수 있는 이유와, 전선 후보마다 `visited`를 새로 만들면 방문 해제가 필요 없는 이유를 설명한다.
- `입국심사` D+3: 시간 `mid`에서 처리 가능한 인원의 단조성, `right = mid`로 가능한 후보를 유지하는 이유, 탐색 상한의 근거를 2~3분에 회상한다.
