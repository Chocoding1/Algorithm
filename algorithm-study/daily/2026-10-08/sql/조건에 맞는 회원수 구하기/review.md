## Codex 분석

- 복습 등급: A
- 등급 판정 근거: 목표 20분 안인 7분에 힌트 없이 첫 제출로 통과했고, 두 필터 조건의 교집합과 포함 범위를 정확히 구현했으며 문법·결과 오류가 없다.
- 목표 시간 달성: 예 (7분 / 20분)
- 첫 시도 성공: 예
- 핵심 문법: `COUNT(*)`, `WHERE`, `AND`, 두 개의 `BETWEEN`
- 결과 한 행의 단위: 조건을 만족하는 개별 회원 행이 아니라, 모든 조건을 통과한 회원 행의 총개수를 나타내는 집계 결과 한 행이다. 조건을 만족하는 회원이 없어도 값이 `0`인 한 행을 반환한다.
- 쿼리 데이터 흐름: `FROM USER_INFO`가 회원 한 명의 정보를 한 행씩 만들고, `WHERE`가 2021년에 가입했으면서 나이가 20~29세인 행만 남긴다. `COUNT(*)`가 남은 행 수를 세어 `USERS`라는 한 값으로 출력한다.
- 중복·NULL·범위 경계 확인: 두 `BETWEEN`은 시작값과 끝값을 모두 포함하므로 가입일은 2021-01-01과 2021-12-31, 나이는 20과 29를 포함한다. `AGE`나 `JOINED`가 `NULL`이면 범위 비교 결과가 `UNKNOWN`이어서 제외된다. `DISTINCT`가 없으므로 서로 다른 회원 행은 값이 같아도 각각 한 명으로 센다.
- 정답 검증: 문제의 `JOINED`는 `DATE` 타입이므로 `BETWEEN '2021-01-01' AND '2021-12-31'`이 2021년 전체를 정확히 포함한다. `AND`로 두 조건을 동시에 만족하는 회원만 센다.
- 코드 개선 포인트: 현재 쿼리는 충분히 간결하고 정확하다. 날짜 컬럼에 `YEAR(JOINED)`를 적용하는 방법보다 현재 범위 조건이 컬럼을 가공하지 않아 일반적으로 인덱스 활용에도 유리하다. 단, 컬럼이 시각까지 가진 `DATETIME`이라면 상한을 `JOINED < '2022-01-01'`로 쓰는 반열린 범위가 더 안전하다.
- 클린 쿼리 예시:

```sql
SELECT COUNT(*) AS USERS
FROM USER_INFO
WHERE JOINED BETWEEN '2021-01-01' AND '2021-12-31'
  AND AGE BETWEEN 20 AND 29;
```

- 풀이 후 새로 배운 점: `COUNT(*)`는 필터를 통과한 행 전체를 세며, 집계 대상이 0개여도 결과 행 자체는 사라지지 않고 `0`을 반환한다.
- 오류 분류: 없음
- 다음에 적용할 규칙: 날짜 범위는 컬럼 타입과 양 끝 포함 여부를 확인하고, 가능하면 컬럼을 함수로 가공하지 않은 범위 조건으로 작성한다.
