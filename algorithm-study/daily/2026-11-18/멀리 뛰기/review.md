## Codex 분석

- 힌트 수준(Codex 판정): 작은 힌트 — `n = 1`에서 `dp[2]` 접근으로 런타임 오류가 발생하는 반례와 원인을 확인함. 점화식과 DP 구현은 사용자가 독립 설계했고, 나머지 연산 질문은 제출 후 개념 설명으로 처리함
- 복습 등급: B
- 등급 판정 근거: 목표 40분 안인 13분에 성공하고 5분 만에 점화식을 확정했지만, 최소 입력 배열 경계와 매 단계 나머지 연산을 놓쳐 첫 통과 전 오답 2회가 발생했다. `n = 1` 반례에 대한 작은 힌트 후 초기값을 수정해 통과했다.
- 목표 시간 달성: 달성 — 13분 / 40분
- 첫 시도 성공: 아니요 — 첫 통과 전 오답 2회
- 공식 출제 의도 알고리즘: 끝에 도달하는 방법의 수를 이전 두 거리의 결과로 만드는 동적계획법
- Codex 추천 목표 알고리즘: `dp[i] = dp[i - 1] + dp[i - 2]`를 사용하고 매 단계 `1234567`로 나머지를 계산하는 상향식 DP
- 공식 의도 일치 여부: 일치
- Codex 목표 일치 여부: 일치
- 실제 풀이와 의도 알고리즘 비교: 일치. `dp[0] = 1`, `dp[1] = 1`로 두고 2부터 `n`까지 이전 두 값을 합해 모든 이동 순서를 계산했다.
- 풀이 전 사고와 실제 코드의 차이: 풀이 전 기록은 비어 있지만 실제 코드에서는 같은 남은 거리 계산을 재사용하는 점화식을 빠르게 찾았다. 최초 구현은 `dp[1]`, `dp[2]`를 무조건 초기화해 최소 입력을 놓쳤고, 중간 나머지 처리도 제출 과정에서 보완했다.
- 의도 알고리즘 추가 학습 이유: 불필요 — 핵심 점화식은 독립적으로 적용했으며 경계·모듈러 연산만 보완하면 됨
- 풀이 직후 확인한 의도 알고리즘: 마지막 이동이 1칸이면 `i-1`까지 도달한 모든 방법, 2칸이면 `i-2`까지 도달한 모든 방법과 일대일 대응하므로 두 경우를 더한다. 두 집합은 마지막 이동 길이가 달라 겹치지 않는다.
- 대안 학습 상태: 완료 — 배열 DP와 `O(1)` 공간 변수 두 개 방식 비교
- 코드 개선 포인트: 현재 배열 코드는 정확하다. 다음 계산에는 직전 두 값만 필요하므로 길이 `n+1` 배열 대신 변수 두 개로 공간을 `O(1)`로 줄일 수 있다. `MOD`를 상수로 선언하면 숫자의 의미도 분명해진다.
- 클린 코드 예시:

```java
private static final long MOD = 1_234_567L;

public long solution(int n) {
    long twoStepsBefore = 1L; // 0칸까지 도달하는 방법 수
    long oneStepBefore = 1L;  // 1칸까지 도달하는 방법 수

    for (int distance = 2; distance <= n; distance++) {
        long current = (oneStepBefore + twoStepsBefore) % MOD;
        twoStepsBefore = oneStepBefore;
        oneStepBefore = current;
    }

    return oneStepBefore;
}
```

원본 Java는 사용자의 최종 통과 풀이를 보존하기 위해 수정하지 않았다.

- 풀이 후 새로 배운 점: `long`도 `n = 2000`의 전체 가짓수를 담을 수 없으므로 마지막에만 나머지를 구하면 오버플로가 발생한다. `(a + b) % M = ((a % M) + (b % M)) % M`이므로 매 단계 나머지만 저장해도 최종 나머지는 같다.
- 다음 문제에 적용할 한 문장 규칙: 경우의 수 점화식이 덧셈으로 이어지고 최종 나머지만 요구하면, 초기 경계를 먼저 확인하고 매 전이마다 나머지를 계산한다.
- 복습에 포함할 학습 포인트: 마지막 이동 기준으로 경우를 나누는 근거, `dp[0] = 1`의 의미, 최소 입력 배열 경계, 매 단계 나머지 계산의 안전성
- 오류 분류: 구현 — 최소 입력 인덱스 경계·모듈러 연산 시점
- 잘한 점: 점화식을 5분에 독립 확정했고, 전체 탐색 대신 `O(N)` DP를 바로 구현해 목표 시간보다 크게 빠르게 최종 통과했다.
- 개선할 점: 공개 예제에 없는 최소 입력 `n = 1`을 제출 전 직접 실행하고, 반환 조건에 나머지가 명시되면 중간값의 성장과 자료형 한계를 함께 확인해야 한다.
- 유형 인식 신호: 현재 상태의 모든 경우가 마지막 선택에 따라 겹치지 않는 이전 상태들로 나뉘고, 같은 작은 문제의 결과가 반복 사용됨
- 다음에 적용할 규칙: 점화식을 세웠다면 `최소 인덱스`, `초기값`, `반복 시작점`, `나머지 적용 시점`을 한 묶음으로 검증한다.
- 시간복잡도: `2`부터 `n`까지 한 번 순회하므로 `O(N)`
- 공간복잡도: 현재 구현은 `long[n + 1]` 배열을 사용하므로 `O(N)`이며, 직전 두 값만 유지하면 `O(1)`로 줄일 수 있음
