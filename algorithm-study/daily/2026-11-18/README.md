- 목표 시간: 30분

- 플랫폼 / 난이도: 프로그래머스 Lv.2

## MySQL SQL 1문제

### 조건에 맞는 사용자와 총 거래금액 조회하기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/164668
- 플랫폼 / 난이도: 프로그래머스 SQL Lv.3
- 목표 시간: 20분
- 오늘 연습 범주: 1:N JOIN·필터·그룹 집계·`HAVING`
- 결과: 성공 — 11분 30초, 첫 통과 전 오답 1회
- 복습 등급: C
- 핵심 피드백: `DONE`인 개별 게시글은 `WHERE`에서 먼저 거르고, 작성자별 `SUM(PRICE)` 조건은 그룹이 만들어진 뒤 `HAVING`에서 검사한다. 완성 쿼리를 확인했으므로 11월 20일 독립 재작성으로 검증한다.
- 동일 문제 재도전: 2026-11-20, 이전 쿼리 없이 5분
