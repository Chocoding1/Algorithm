## 중간 평가

- `연속된 부분 수열의 합`은 10분 만에 합을 유지하는 두 경계 설계를 확정하고 32분에 힌트·구현 실수 없이 첫 제출로 통과해 A등급이다.
- 두 경계가 각각 한 방향으로 최대 `N`번 이동하므로 시간복잡도는 `O(N)`이다. 같은 길이의 구간은 더 앞선 후보가 먼저 발견되므로 더 짧은 경우에만 갱신한 현재 코드도 정확하다.
- 현재 구현은 충분히 효율적이다. 경계 검사와 `continue`를 줄인 가독성 개선 코드는 문제별 `review.md`에 기록했고 원본 Java는 수정하지 않았다.
- 실제 완료일을 기준으로 2026-10-21에 D+3 짧은 회상, 2026-10-25에 유형 비공개 신규 변형을 편성한다.
- `구명보트`는 7분 만에 첫 설계를 확정했지만 한 보트 최대 2명 제약을 누락한 누적 방식으로 오답이 발생했다. 이후 가장 무거운 사람과 가장 가벼운 사람을 비교하는 핵심 선택 규칙을 힌트로 확인해 30분에 통과했으므로 C등급이다.
- 최종 코드는 정렬 후 두 인덱스를 이동하는 `O(N log N)` 정답이다. 조건식 안의 `right--`와 마지막 한 명 처리를 분리한 가독성 개선 코드는 문제별 `review.md`에 기록했고 원본 Java는 수정하지 않았다.
- 2026-10-20에 현재 코드·회고 없이 동일 문제를 재도전하고, 성공하면 2026-10-27에 유형 비공개 신규 변형으로 전이를 확인한다.
- SQL `경기도에 위치한 식품창고 목록 출력하기`는 지역 필터와 정렬을 포함한 전체 쿼리를 5분에 완성해 첫 제출로 통과했다. 다만 `DEFAULT`와 조회 시 `NULL` 대체를 혼동해 `COALESCE`의 현재 컬럼 적용 예를 작은 힌트로 확인했으므로 B등급이다.
- 원본 쿼리는 정확하다. `COALESCE` 결과에 `AS FREEZER_YN` 별칭을 붙인 명시적인 쿼리는 문제별 `review.md`에 기록했고 원본 SQL은 수정하지 않았다. 2026-10-21에 5분 이내 짧은 재작성으로 문법을 확인한다.
- SQL `고양이와 개는 몇 마리 있을까`는 이전 자료 없이 5분에 그룹 집계와 `ORDER BY ANIMAL_TYPE`을 모두 재현해 재도전 첫 제출로 통과했다. 이전 정렬 누락이 재발하지 않았으므로 재도전 A등급으로 완료 처리한다.
- 현재 쿼리는 정확하며 `COUNT(*) AS count`는 행 수와 출력 이름의 의도를 더 명시하는 가독성 대안이다. 추가 동일 문제 재도전은 하지 않는다.
