- 실제 풀이와 의도 알고리즘 비교: 현재 풀이는 회전 대상 네 변을 직접 순회해 새 위치를 계산하므로 핵심 접근은 적절하다. 다만 매 회전마다 행렬 전체 크기의 `temp`를 생성하지만 실제로 사용하는 값은 테두리뿐이다.

- 의도 알고리즘 추가 학습 이유: 정답 접근은 이미 구현했다. 전체 임시 행렬 없이 값 하나만 보관하며 네 변을 제자리에서 이동하면 같은 동작을 더 적은 할당과 단순한 경계로 표현할 수 있다.
- 풀이 직후 확인한 의도 알고리즘: 회전 전 모서리 값 하나를 보관하고, 덮어써도 안전한 순서로 네 변을 차례로 이동한다. 각 칸을 옮길 때 최솟값도 함께 갱신하며, 한 회전은 테두리 길이에 비례한다.
- 대안 학습 상태: 완료 — 제자리 회전 예시와 복잡도 차이를 아래에 기록
- 코드 개선 포인트: **빅오 및 메모리 할당 개선.** 현재 `new int[rows + 1][columns + 1]`은 자바에서 모든 칸을 0으로 초기화하므로, 테두리만 순회하더라도 회전당 `O(rows × columns)` 비용과 전체 행렬 크기의 임시 메모리 할당이 발생한다. 값 하나만 보관해 제자리 회전하면 회전당 `O(테두리 길이)`로 줄고 반복적인 2차원 배열 할당도 없어진다. `move()`의 범위를 벗어난 칸에 값을 쓴 뒤 `changeOrigin()`에서 사용하지 않는 방식과 불필요한 `break` 조건도 함께 사라진다.
- 풀이 후 새로 배운 점: 배열 값을 연쇄적으로 이동할 때는 전체 복사본이 항상 필요한 것이 아니다. 덮어쓰기 전에 사라질 값 하나를 보관하고, 이미 읽은 방향으로 갱신하면 `O(1)` 추가 공간으로 제자리 이동할 수 있다.
- 다음 문제에 적용할 한 문장 규칙: 일부 구간만 움직이는 문제에서는 전체 복사본을 만들기 전에, 덮어쓰기 때문에 잃는 값이 몇 개인지부터 확인한다.
- 복습에 포함할 학습 포인트: 11월 22일 D+3에 `temp` 전체 할당이 실제로 `O(rows × columns)`인 이유와 값 하나로 네 변을 이동하는 순서를 3분 이내로 회상한다.
- 오류 분류: 없음
- 잘한 점: 1기반 좌표 행렬을 사용해 문제 좌표 변환 실수를 피했고, 네 방향의 이동과 최솟값 계산을 한 회전에 함께 처리했다. 연속된 `queries`가 변경된 `origin`을 사용하도록 상태도 정확히 유지했다.
- 개선할 점: 테두리보다 훨씬 큰 전체 임시 행렬을 매번 생성하지 않고, 루프 범위를 각 변의 실제 시작·끝에 맞춰 모서리를 정확히 한 번만 처리한다.
- 유형 인식 신호: 작은 2차원 상태에 여러 변경 명령을 순서대로 적용하고, 각 명령에서 변경된 값의 통계를 요구한다.
- 다음에 적용할 규칙: 변경 대상이 테두리라면 네 변의 총 길이만큼만 처리하고, 다음 명령이 현재 상태를 이어받도록 같은 행렬을 갱신한다.
- 시간복잡도: 현재 코드 `O(rows × columns + queries.length × rows × columns)` — 임시 2차원 배열 초기화가 지배. 제자리 개선안은 `O(rows × columns + Σ 각 query의 테두리 길이)`
- 공간복잡도: 현재 코드의 최대 동시 공간 `O(rows × columns)`이며 회전마다 같은 크기의 임시 배열을 새로 할당한다. 제자리 개선안도 원본 행렬 때문에 전체 공간은 `O(rows × columns)`이지만 회전당 추가 공간은 `O(1)`이다.

### 클린 코드 예시

원본 Java는 풀이 기록 보존을 위해 수정하지 않는다. 아래 코드는 전체 임시 행렬 없이 테두리만 제자리에서 회전한다.

```java
public int[] solution(int rows, int columns, int[][] queries) {
    int[][] matrix = new int[rows + 1][columns + 1];
    int value = 1;

    for (int row = 1; row <= rows; row++) {
        for (int col = 1; col <= columns; col++) {
            matrix[row][col] = value++;
        }
    }

    int[] answer = new int[queries.length];
    for (int i = 0; i < queries.length; i++) {
        answer[i] = rotateBorder(matrix, queries[i]);
    }
    return answer;
}

private int rotateBorder(int[][] matrix, int[] query) {
    int top = query[0];
    int left = query[1];
    int bottom = query[2];
    int right = query[3];

    int savedTopLeft = matrix[top][left];
    int min = savedTopLeft;

    for (int row = top; row < bottom; row++) {
        matrix[row][left] = matrix[row + 1][left];
        min = Math.min(min, matrix[row][left]);
    }

    for (int col = left; col < right; col++) {
        matrix[bottom][col] = matrix[bottom][col + 1];
        min = Math.min(min, matrix[bottom][col]);
    }

    for (int row = bottom; row > top; row--) {
        matrix[row][right] = matrix[row - 1][right];
        min = Math.min(min, matrix[row][right]);
    }

    for (int col = right; col > left + 1; col--) {
        matrix[top][col] = matrix[top][col - 1];
        min = Math.min(min, matrix[top][col]);
    }

    matrix[top][left + 1] = savedTopLeft;
    return min;
}
```
