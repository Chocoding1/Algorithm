- 실제 풀이와 의도 알고리즘 비교: 문자열을 실제로 회전하거나 복사하지 않고 `(i + j) % s.length()`로 각 회전의 문자를 읽으며, 여는 괄호를 스택에 넣고 닫는 괄호가 나오면 가장 최근 여는 괄호와 짝을 검사함
- 풀이 전 사고와 실제 코드의 차이: 풀이 전 정한 회전별 스택 검사를 그대로 구현했지만, 처음에는 마지막 문자의 짝만 맞으면 성공으로 세어 스택에 여는 괄호가 남은 경우를 놓쳤다. 최종 코드는 마지막 위치에서 `stack.isEmpty()`까지 확인하도록 수정됨
- 코드 개선 포인트: 현재 코드는 제한에서 정답이고 `O(N²)`도 충분하다. 다만 두 `List<Character>`에서 `contains`와 `indexOf`로 괄호 대응을 찾으면 박싱과 선형 검색이 생기고 짝 관계가 분산된다. `switch`로 각 닫는 괄호의 짝을 바로 검사하고, 내부 반복 종료 후에만 성공을 세면 성공 조건이 더 명확하다. 빅오 개선이 아니라 상수 비용·가독성·안전성 개선이다.
- 클린 코드 예시:

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class 괄호_회전하기 {
    public int solution(String s) {
        if (s.length() % 2 == 1) {
            return 0;
        }

        int answer = 0;
        for (int start = 0; start < s.length(); start++) {
            if (isValidRotation(s, start)) {
                answer++;
            }
        }
        return answer;
    }

    private boolean isValidRotation(String s, int start) {
        Deque<Character> stack = new ArrayDeque<>();

        for (int offset = 0; offset < s.length(); offset++) {
            char bracket = s.charAt((start + offset) % s.length());

            switch (bracket) {
                case '(', '{', '[' -> stack.push(bracket);
                case ')' -> {
                    if (stack.isEmpty() || stack.pop() != '(') return false;
                }
                case '}' -> {
                    if (stack.isEmpty() || stack.pop() != '{') return false;
                }
                case ']' -> {
                    if (stack.isEmpty() || stack.pop() != '[') return false;
                }
            }
        }

        return stack.isEmpty();
    }
}
```

- 풀이 후 새로 배운 점: 괄호 문자열은 모든 문자를 처리했다는 사실만으로 유효하지 않다. 도중의 닫는 괄호가 스택의 top과 모두 맞아야 하고, 처리가 끝난 뒤 남은 여는 괄호도 없어야 한다.
- 다음 문제에 적용할 한 문장 규칙: 스택으로 짝을 검사할 때는 `도중 불일치 없음`과 `종료 후 스택이 비어 있음`을 별개의 성공 조건으로 확인한다.
- 복습에 포함할 학습 포인트: 회전 인덱스 식, 닫는 괄호별 top 검사, 종료 후 빈 스택 조건, 각 회전을 모두 검사해 `O(N²)`이 되는 이유
- 오류 분류: 설계·구현 — 회전 접근식 도움을 받았고, 종료 후 남은 여는 괄호를 검사하지 않아 오답 제출 1회
- 시간복잡도: `O(N²)` — `N`개 시작 위치마다 최대 `N`개 문자를 검사
- 공간복잡도: `O(N)` — 한 회전에서 여는 괄호가 모두 스택에 쌓일 수 있음
