## Codex 분석

- 힌트 수준(Codex 판정): 작은 힌트 — DFS와 방문 배열 설계는 이미 독립적으로 완성했으며, 오답 후 이웃 탐색 범위를 `comIdx + 1`이 아니라 전체 `0..n-1`로 고치는 구현 오류를 진단받음
- 복습 등급: B
- 등급 판정 근거: 그래프의 연결 요소를 DFS로 세는 핵심 설계를 7분 만에 독립적으로 확정하고 20분에 최종 통과했지만, 탐색 범위를 잘못 제한해 첫 통과 전 오답 제출이 1회 있었고 해당 오류를 작은 힌트로 수정함
- 목표 시간 달성: 일요일 세트 전체 기준으로 판정
- 첫 시도 성공: 실패 — 이웃 탐색을 현재 인덱스 뒤로 제한한 코드로 오답 후 수정
- 공식 출제 의도 알고리즘: 프로그래머스 DFS/BFS 분류 — DFS 또는 BFS로 연결 요소 탐색
- Codex 추천 목표 알고리즘: 방문하지 않은 컴퓨터마다 DFS를 시작해 연결 요소 개수 계산
- 공식 의도 일치 여부: 일치 — DFS 사용
- Codex 목표 일치 여부: 일치
- 실제 풀이와 의도 알고리즘 비교: 바깥 반복문에서 아직 방문하지 않은 컴퓨터를 발견할 때마다 네트워크 수를 하나 늘리고, 인접 행렬의 연결된 모든 컴퓨터를 DFS로 방문 처리하는 표준 연결 요소 풀이
- 풀이 전 사고와 실제 코드의 차이: 전체 컴퓨터에서 미방문 정점을 찾아 DFS를 시작한다는 설계는 정확했다. 처음 구현에서는 바깥 반복문의 진행 순서와 DFS 내부의 이동 방향을 혼동해 현재 번호보다 큰 이웃만 검사했지만, 연결 경로는 번호 순서를 따르지 않으므로 최종 코드에서는 모든 열을 검사함
- 코드 개선 포인트: 최종 코드는 정확하고 `O(N²)`이 최선이다. `visited[computer] = true`를 DFS 진입부에 모으면 모든 호출의 방문 처리 규칙이 한곳에 위치하고, `n`은 `computers.length`로 알 수 있어 재귀 매개변수에서 제거할 수 있다. 빅오 개선은 아니며 가독성과 불변식 집중 개선이다.
- 클린 코드 예시:

```java
public class 네트워크 {
    private boolean[] visited;

    public int solution(int n, int[][] computers) {
        visited = new boolean[n];
        int networks = 0;

        for (int computer = 0; computer < n; computer++) {
            if (!visited[computer]) {
                dfs(computer, computers);
                networks++;
            }
        }

        return networks;
    }

    private void dfs(int computer, int[][] computers) {
        visited[computer] = true;

        for (int next = 0; next < computers.length; next++) {
            if (computers[computer][next] == 1 && !visited[next]) {
                dfs(next, computers);
            }
        }
    }
}
```

- 풀이 후 새로 배운 점: 바깥 반복문이 정점을 번호순으로 확인하더라도 DFS는 연결 간선을 따라 이동하므로 현재 정점보다 작은 번호로 되돌아갈 수 있다. 인접 행렬의 한 행에서는 방문 여부와 무관하게 모든 열을 후보로 검사해야 한다.
- 대안 풀이 학습: 연결된 두 컴퓨터를 같은 집합으로 합친 뒤 서로 다른 루트 수를 세는 Union-Find로도 풀 수 있다. 이 문제는 인접 행렬 전체를 읽어야 하므로 DFS와 Union-Find 모두 전체 시간은 `O(N²)`이며, 연결 요소를 한 번 세는 현재 문제에는 DFS가 더 직접적이다. 간선이 순차적으로 추가되거나 연결 여부 질의가 반복되면 Union-Find를 우선 검토한다.
- 다음 문제에 적용할 한 문장 규칙: 그래프 탐색의 이웃 범위는 정점 번호의 처리 순서가 아니라 실제 간선 관계로 정한다.
- 복습에 포함할 학습 포인트: 미방문 정점마다 연결 요소가 하나 추가되는 이유, DFS에서 모든 이웃을 확인해야 하는 이유, 인접 행렬 DFS의 `O(N²)` 근거
- 오류 분류: 구현 — 바깥 순회 순서와 DFS의 이웃 범위를 혼동해 낮은 번호로 이어지는 경로를 누락
- 시간복잡도: `O(N²)` — 각 컴퓨터를 방문할 때 인접 행렬의 한 행 `N`칸을 확인
- 공간복잡도: `O(N)` — 방문 배열과 최악의 경우 깊이 `N`의 재귀 호출 스택
