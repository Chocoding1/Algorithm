# 알고리즘 학습 대시보드

## 기준선

- 언어: Java
- 과거 수준: 백준 Gold 1
- 현재 체감 수준: 프로그래머스 Lv.2 초반
- 1차 목표: 2026년 10월 말~11월 초 국내 백엔드 코딩테스트 응시 수준 도달
- 목표선: 어려운 Lv.2 안정화, 핵심 유형 Lv.3 입문, 유형 비공개 3문제 120분에서 최소 2문제 완전 해결
- 빈도: 월요일~금요일 알고리즘 2문제 + SQL 2문제, 일요일 알고리즘 3문제 120분 실전 + SQL 주간 혼합 2문제, 토요일 휴식
- 시작일: 첫 실제 풀이 기록일

- 첫 시도 성공률: 71.4% (15/21, `주식가격` 1건 미확인)
- 목표 시간 달성률: 64% (16/25, 일요일 세트 내 개별 목표 없는 재도전 1회 제외)
- 실제 풀이 시간 중앙값: 24.5분
- 힌트·해설 의존률: 32.1% (9/28)
- 인식 실패: 4
- 설계 실패: 5
- 구현 실패: 9
- 시간 관리 실패: 9
- A등급: 8문제 (28.6%)
- B등급: 14문제 (50%)
- C등급: 6문제 (21.4%)

- 유효한 대안 풀이 비율: 100% (2/2)
- 의도 알고리즘 보완 완료율: 100% (5/5, `두 큐 합 같게 만들기` 핵심 흐름 독립 재현·자료형 안전성 별도 보완)

등급 분포만으로 실력을 평가하지 않습니다. 첫 시도 성공률, 목표 시간 달성률, 힌트·해설 의존률, 오류 유형과 D+7 변형 문제 전이 성공률을 함께 평가합니다.

## SQL 누적 지표

- 총 풀이 수: 12 (동일 문제 재도전 1회 포함)
- 첫 제출 성공률: 72.7% (8/11, 동일 문제 재도전 제외)
- 목표 시간 달성률: 100% (12/12)
- 힌트·해설 의존률: 33.3% (4/12)
- 문법·결과 오류: 4문제 (`ORDER BY` 누락 2, 집계 결과 행 단위·`DISTINCT` 오류 1, 식별자 인용·날짜 필터 문법 1)
- 결과 행 단위 설명 충족률: 91.7% (11/12)
- 중복·NULL 영향 설명 충족률: 83.3% (10/12)
- A등급: 6문제 (50%)
- B등급: 3문제 (25%)
- C등급: 3문제 (25%)
- 동일 문제 재도전 성공률: 100% (1/1, 쿼리 독립 재현 성공·개념 설명은 B등급 복습 유지)
- 주간 혼합 전이 성공률: 100% (1/1)

SQL 지표는 알고리즘 지표와 분리합니다. 2주차 집계·`NULL` 학습에서 `중복 제거하기`는 이전 쿼리 없이 5분에 첫 제출로 재현했고, `동명 동물 수 찾기`는 `GROUP BY`와 `HAVING`을 4분에 독립 적용해 A등급을 받았다. 집계 쿼리 작성 속도와 정확성은 좋아지고 있지만, `COUNT(DISTINCT)`가 단일 결과를 만드는 것과 `GROUP BY`가 이름별 여러 행을 만드는 차이는 제출 후 다시 질문했다. 10월 17일에 이 결과 행 단위만 5분 이내로 설명·재작성해 안정화한다. 예정된 `고양이와 개는 몇 마리 있을까`, `진료과별 총 예약 횟수 출력하기` 재도전도 유지한다.

## 지표 산정 기준

- 첫 시도 성공률: 신규 문제 중 첫 공식 제출이 통과한 문제 수 / 신규 문제 수
- 목표 시간 달성률: 성공하면서 실제 풀이 시간이 목표 시간 이하인 문제 수 / 실제 풀이 시간이 기록된 문제 수
- 힌트·해설 의존률: 작은 힌트·핵심 힌트·해설·정답 코드를 하나라도 사용한 문제 수 / 전체 풀이 수
- 오류 유형 비율: 해당 오류가 기록된 문제 수 / 전체 풀이 수. 한 문제에 여러 오류가 있으면 각 오류에 모두 반영합니다.
- D+7 변형 전이 성공률: 핵심 힌트·해설·정답 코드 없이 성공한 D+7 변형 수 / 실제로 풀이한 D+7 변형 수
- 같은 실수 재발률: 과거에 기록된 동일 오류가 다시 발생한 문제 수 / 이전 오류 이력이 있는 문제 수
- 출제 의도 알고리즘 사전 인식률: Codex 피드백 전에 작성한 추측이 공식 의도와 일치한 문제 수 / 공식 의도가 명시되고 추측이 기록된 문제 수
- Codex 목표 알고리즘 사전 인식률: Codex 피드백 전에 작성한 추측이 Codex 목표와 일치한 문제 수 / 목표가 정해지고 추측이 기록된 문제 수
- 유효한 대안 풀이 비율: 의도와 다른 알고리즘 중 정확하고 제한을 충분히 만족한 문제 수 / 의도와 다른 알고리즘으로 푼 문제 수
- 의도 알고리즘 보완 완료율: 설명·의사코드·변형 문제 등 지정된 보완을 완료한 문제 수 / 보완이 필요하다고 판정된 문제 수

## 최근 평가

총 28회 풀이 중 26회는 플랫폼에서 최종 성공했다. 10월 14일 `소수 찾기`는 순열 백트래킹을 7분 만에 독립 설계해 최근 상태 공간 탐색 학습을 새 입력에 적용했다. 다만 제곱근과 같은 약수를 제외한 구현 오류로 오답 1회와 작은 힌트가 발생해 D+7 전이는 부분 성공이고 B등급이다. 다음 보완점은 재귀 상태를 사용한 조각 수와 일치시키고, 소수 판정의 경계를 `divisor * divisor <= number`로 안정화하는 것이다.
