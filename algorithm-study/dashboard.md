## 최근 평가

총 45회 알고리즘 풀이 중 38회는 플랫폼에서 최종 성공했다. `프렌즈4블록`은 같은 턴의 삭제 위치를 별도로 표시하는 방향은 맞았지만, 원본 보드와 누적 삭제 정보로 중력을 간접 표현하면서 원본 행과 현재 행을 혼동해 90분 이상·최종 미통과로 끝났다. 현재 `char[][]`를 직접 갱신하는 `탐색 → 일괄 삭제 → 중력` 구조와 완성 코드를 학습했으므로 C등급이며 2026-11-19에 재도전한다. `땅따먹기`는 90분 동안 누적 상태를 확정하지 못하고 정답 코드를 확인해 C등급이며 재도전이 아직 남아 있다. 최근 두 신규 문제에서 복잡한 상태를 간접 표현해 설계·구현 시간이 커졌으므로, 다음 구현에서는 현재 상태가 자료구조에 직접 드러나는지 먼저 확인한다.

총 41회 알고리즘 풀이 중 37회는 플랫폼에서 최종 성공했다. `입국심사`에서는 직접 배분의 조합 폭발은 인식했지만 정답 시간을 결정 문제로 바꾸는 단조성 전환을 독립적으로 완성하지 못해 최초 C등급을 받았고, 2026-11-09 재도전에서 판정식·탐색 범위·경계 갱신을 15분에 독립 재현해 A등급으로 회복했다.

`주차 요금 계산`은 차량별 상태 관리와 미출차 후처리를 독립 설계해 첫 제출로 통과했다. 공식 해설의 배열 인덱스 방식 대신 `HashMap`·`TreeMap`을 사용한 흐름도 정확하지만, 40분 목표에 70분이 걸렸고 정수 올림식의 경계 오류를 도움받아 수정했으므로 B등급이다. 다음 구현 문제에서는 설계 확정 후 시각 변환·후처리·요금 계산을 작은 함수 단위로 나눠 검증하는 연습이 필요하다.

`정수 삼각형`은 첫 제출에서 모든 경로를 다시 계산해 시간 초과가 발생했지만, 같은 `(행, 열)`에서 아래쪽 최대 합이 항상 같다는 점을 찾아 메모이제이션으로 수정하고 24분에 통과했다. 목표 시간 내 독립 수정은 긍정적이지만 유형이 사전 노출됐고 최초 복잡도 판단을 놓쳤으므로 B등급이며, 다음 변형에서는 상태 수를 먼저 세어 완전 재귀와 DP의 차이를 구현 전에 판별해야 한다.

`전력망을 둘로 나누기`는 2026-11-11 재도전에서 DFS가 연결 요소의 크기를 반환하게 만들고, 한쪽이 `count`면 다른 쪽이 `n-count`인 구조를 힌트 없이 독립 재현했다. 45분으로 목표를 초과하고 DFS 반환 후 방문 해제를 누락했다가 수정한 부분은 보완점이지만, 최초 C등급의 핵심 설계를 다시 재현했으므로 재재도전은 하지 않는다. 다음에는 전선 후보마다 새 `visited`를 만들어 탐색 상태를 독립시키는 구조로 구현 부담을 줄인다.

`입국심사`는 최초 풀이에서 정답 코드로 학습했던 시간 판정식과 이분 탐색 경계를 2026-11-09 재도전에서 추가 도움 없이 독립 재현했다. 7분 만에 설계를 확정하고 15분에 첫 제출로 통과했으며 `min(times) × n` 상한과 `long` 자료형도 정확해 A등급이다. 다음 단계는 2026-11-16 유형 비공개 변형에서 같은 단조성 전환을 처음 보는 조건에 적용하는 것이다.

`배달`은 가중치가 있는 이동 문제에서 누적 시간이 가장 작은 후보부터 처리하는 설계를 13분에 확정하고 39분 30초에 첫 제출로 통과했다. 거리 배열 없이 `visited`와 우선순위 큐만으로도 양의 가중치에서 첫 poll이 최소 시간을 확정한다는 구조가 정확해 A등급이다. 다음에는 `dist` 완화 조건을 사용해 더 느린 중복 후보를 줄이고 상태의 의미를 코드에 직접 표현하는 연습을 한다.

`가장 먼 노드`는 모든 간선의 이동 횟수가 같은 조건을 확인하고 일반 큐 BFS로 2분 만에 설계를 확정해 13분에 첫 제출로 통과했다. 같은 날 `배달`에서는 누적 비용이 작은 후보를 우선했으므로, 무가중과 가중 최단거리의 처리 순서를 실제 코드로 구분한 점이 긍정적이다. 가능한 모든 경로를 직접 나열하면 지수적으로 증가할 수 있다는 복잡도 판단만 D+3에서 함께 회상한다.

`섬 연결하기`는 비용이 낮은 간선부터 서로 다른 연결 요소를 합치는 Kruskal과 Union-Find를 15분에 독립 설계했다. 첫 구현에서는 정점 방문 여부로 연결 요소를 대신했고, 다음 구현에서는 대표가 아닌 원래 정점 번호를 연결해 오답 2회가 발생했지만 반례를 통해 대표끼리 합쳐야 기존 집합 관계가 유지된다는 점을 수정해 30분에 통과했다. 핵심 유형 인식은 성공했으므로 동일 문제 재도전보다 D+1·D+3에서 상태 표현과 구현 규칙을 안정화한다.

`합승 택시 요금`은 다익스트라를 떠올리고 합승 종료 후보마다 두 목적지까지 다시 탐색하면 반복 비용이 커진다는 병목까지 정확히 확인했다. 그러나 60분 동안 양방향 거리 대칭성을 이용해 `s`, `a`, `b`의 세 거리 배열을 미리 계산하는 설계로 전환하지 못했고, 정답 코드와 플로이드–워셜 대안을 학습해 C등급이다. 실제 학습일 다음 날의 즉시 재도전을 피하고 같은 날 배운 `순위`와 일정을 분리해, 2026-11-16 재도전에서 합승 종료 지점 `k`를 고정한 세 구간 합을 먼저 적고 한 방식만 선택해 독립 재현한다.
