# 알고리즘 학습 대시보드

## 기준선

- 언어: Java
- 과거 수준: 백준 Gold 1
- 현재 체감 수준: 프로그래머스 Lv.2 초반
- 1차 목표: 2026년 10월 말~11월 초 국내 백엔드 코딩테스트 응시 수준 도달
- 목표선: 어려운 Lv.2 안정화, 핵심 유형 Lv.3 입문, 유형 비공개 3문제 120분에서 최소 2문제 완전 해결
- 빈도: 월요일~금요일 알고리즘 2문제 + SQL 1문제, 일요일 알고리즘 3문제 120분 실전 + SQL 주간 혼합 1문제, 토요일 휴식
- 시작일: 첫 실제 풀이 기록일

- 총 풀이 수: 5
- 첫 제출 성공률: 100% (5/5)
- 목표 시간 달성률: 100% (5/5)
- 힌트·해설 의존률: 20% (1/5)
- 문법·결과 오류: 1문제 (`ORDER BY` 누락)
- 결과 행 단위 설명 충족률: 100% (5/5)

SQL 지표는 알고리즘 지표와 분리합니다. 현재 표본은 5문제이므로 속도나 등급만으로 SQL 실력을 판단하지 않고, 앞으로 결과 행의 단위·중복·NULL·JOIN·그룹 단위 설명과 주간 혼합 문제의 독립 성공 여부를 함께 봅니다. `SELECT`·`FROM`·기본 `WHERE`·다중 조건·범위 집계 작성 속도는 안정적이며, 이전에 누락했던 정렬도 10월 8일 독립 재작성에서 정확히 보완했다. 문자열 포함 조건은 작은 힌트로 학습했으므로 10월 11일 주간 혼합 문제에서 독립 적용 여부를 확인한다.

## 지표 산정 기준

- 첫 시도 성공률: 신규 문제 중 첫 공식 제출이 통과한 문제 수 / 신규 문제 수
- 목표 시간 달성률: 성공하면서 실제 풀이 시간이 목표 시간 이하인 문제 수 / 실제 풀이 시간이 기록된 문제 수
- 힌트·해설 의존률: 작은 힌트·핵심 힌트·해설·정답 코드를 하나라도 사용한 문제 수 / 전체 풀이 수
- 오류 유형 비율: 해당 오류가 기록된 문제 수 / 전체 풀이 수. 한 문제에 여러 오류가 있으면 각 오류에 모두 반영합니다.
- D+7 변형 전이 성공률: 핵심 힌트·해설·정답 코드 없이 성공한 D+7 변형 수 / 실제로 풀이한 D+7 변형 수
- 같은 실수 재발률: 과거에 기록된 동일 오류가 다시 발생한 문제 수 / 이전 오류 이력이 있는 문제 수
- 출제 의도 알고리즘 사전 인식률: Codex 피드백 전에 작성한 추측이 공식 의도와 일치한 문제 수 / 공식 의도가 명시되고 추측이 기록된 문제 수
- Codex 목표 알고리즘 사전 인식률: Codex 피드백 전에 작성한 추측이 Codex 목표와 일치한 문제 수 / 목표가 정해지고 추측이 기록된 문제 수
- 유효한 대안 풀이 비율: 의도와 다른 알고리즘 중 정확하고 제한을 충분히 만족한 문제 수 / 의도와 다른 알고리즘으로 푼 문제 수
- 의도 알고리즘 보완 완료율: 설명·의사코드·변형 문제 등 지정된 보완을 완료한 문제 수 / 보완이 필요하다고 판정된 문제 수

## 최근 평가

총 19회 풀이 중 17회는 최종 성공했다. `게임 맵 최단거리`에서는 최단거리 신호를 보고 7분 만에 BFS를 선택해 27분에 첫 제출로 통과했으며, 큐 삽입 시 방문 처리와 `O(N×M)` 구현도 정확했다. 이는 백트래킹·DFS 상태 생성 다음 단계인 BFS 진입이 안정적이었다는 근거다. `두 큐 합 같게 만들기`는 10월 11일 독립 재도전에서 `asLongStream()` 또는 직접 `long` 누적, 마지막 이동 후 성공 검사를 함께 재현해야 한다. 앞으로 힌트 수준은 사용자의 자기 신고 대신 실제 대화에서 제공한 상태·진행 규칙·종료 조건과 코드 노출 정도를 Codex가 판정한다.
